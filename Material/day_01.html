Module 1 — Python Foundations

1.0 History & Evolution of Python in AI

Python was created by Guido van Rossum in 1989 (first released in 1991) at CWI in the Netherlands. Designed as a general-purpose language emphasizing code readability and programmer productivity, Python has evolved into the undisputed lingua franca of Artificial Intelligence and Machine Learning.

  • Why Python Became Dominant in AI: Readability, intuitive syntax, and a massive ecosystem of specialized libraries (NumPy, PyTorch, Pydantic, FastAPI).
  • Python vs C/C++/Java for AI: C/C++ offers raw speed but slow development iteration. Java offers enterprisey verbosity. Python acts as the high-level "glue" interface, running underlying computations via C/C++/Rust C-extensions.
  • CPython & The Interpreter: The standard Python implementation compiles .py code into bytecode, which is executed by the CPython virtual machine.
  • Python 2 vs Python 3: Python 3 (released in 2008) resolved text encoding ambiguities by enforcing UTF-8 unicode strings by default and modernizing division operators.

Module 6 — Error Handling & Debugging

6.1 Exceptions, 6.2 Handling & 6.5 Network Retry Example


# Program 6.1: Resilient Retry Engine with Custom Exceptions
import time
import random

class APIQuotaExceededError(Exception):
    pass

def call_mock_llm_api(prompt: str) -> str:
    if random.random() < 0.6:
        raise APIQuotaExceededError("HTTP 429: Rate Limit Exceeded")
    return f"Response to '{prompt}'"

def resilient_llm_call(prompt: str, max_retries: int = 3) -> str:
    for attempt in range(1, max_retries + 1):
        try:
            return call_mock_llm_api(prompt)
        except APIQuotaExceededError as err:
            print(f"⚠️ [Attempt {attempt}/{max_retries}] Caught Error: {err}. Retrying in 0.5s...")
            time.sleep(0.5)
    raise RuntimeError("Exhausted all retries calling LLM API.")

try:
    result = resilient_llm_call("Summarize legal contract")
    print(f"✓ LLM Call Success: {result}")
except RuntimeError as exc:
    print(f"🚨 Fatal Pipeline Error: {exc}")

# Program 9.1: Object-Oriented Agent Architecture & Dataclasses
from dataclasses import dataclass, field
from typing import List

@dataclass
class Tool:
    name: str
    description: str

class Agent:
    def __init__(self, model_name: str, tools: List[Tool]):
        self.model_name = model_name
        self.tools = tools
        self.memory: List[str] = []

    def execute(self, task: str) -> str:
        self.memory.append(task)
        tool_names = ", ".join([t.name for t in self.tools])
        return f"Agent({self.model_name}) executed task '{task}' using tools: [{tool_names}]"

# Instantiate Agent

Module 12 — Pydantic: Runtime Validation & Structured Output

12.1 Runtime Validation & 12.6 LLM -> Pydantic Schema Validation


# Program 12.1: Pydantic v2 Model & Field Validator
from pydantic import BaseModel, Field, field_validator, ValidationError

class SQLQuerySchema(BaseModel):
    query: str = Field(..., description="SQL SELECT statement")
    tables: list[str] = Field(..., min_length=1)

    @field_validator("query")
    @classmethod
    def reject_destructive_sql(cls, v: str) -> str:
        if any(keyword in v.upper() for keyword in ["DROP", "DELETE", "TRUNCATE"]):
            raise ValueError("Security Violation: Destructive SQL keyword detected.")
        return v

valid_json = '{"query": "SELECT name FROM users", "tables": ["users"]}'
model = SQLQuerySchema.model_validate_json(valid_json)
print(f"✓ Validated SQL Model Query: {model.query}")

Module 15 — Asynchronous Python (asyncio)

15.1 Sync vs Async & 15.6 Concurrent Tasks (asyncio.gather)


# Program 15.1: High-Throughput Async Ingestion Pipeline
import asyncio
import time

async def fetch_document_async(doc_id: int) -> dict:
    await asyncio.sleep(0.3)
    return {"doc_id": doc_id, "content": f"Content of document #{doc_id}"}

async def main_async_pipeline():
    start = time.perf_counter()
    tasks = [fetch_document_async(i) for i in range(1, 6)]
    results = await asyncio.gather(*tasks)
    elapsed = time.perf_counter() - start
    print(f"Fetched {len(results)} documents concurrently in {elapsed:.2f} seconds.")

asyncio.run(main_async_pipeline())

# Program 16.1: Production Full-Jitter Exponential Backoff Calculation
import random

def calculate_jitter_backoff(attempt: int, base_delay: float = 0.5, max_delay: float = 8.0) -> float:
    ceiling = min(max_delay, base_delay * (2 ** attempt))
    sleep_time = random.uniform(base_delay, ceiling)
    return sleep_time

for attempt in range(4):
    delay = calculate_jitter_backoff(attempt)
    print(f"Attempt #{attempt + 1}: Backoff delay = {delay:.2f}s")

18.1 Calling LLMs, 18.4 Tool Calling & 18.5 End-to-End Agent Loop


# Program 18.1: Complete End-to-End AI Agent Tool Calling Loop Architecture
from dataclasses import dataclass
from typing import List, Dict, Any

@dataclass
class ToolDefinition:
    name: str
    func: Any

def web_search(query: str) -> str:
    return f"Search Results for '{query}': AI Agents require deterministic safety gates."

def calculator(expr: str) -> str:
    return f"Calculation Result for '{expr}': 42"

class AutonomousAgent:
    def __init__(self):
        self.tools: Dict[str, Any] = {
            "web_search": web_search,
            "calculator": calculator
        }
        self.state: List[Dict[str, str]] = []

    def run(self, user_prompt: str) -> str:
        self.state.append({"role": "user", "content": user_prompt})
        
        if "search" in user_prompt.lower():
            tool_name = "web_search"
            result = self.tools[tool_name](user_prompt)
        elif "calculate" in user_prompt.lower():
            tool_name = "calculator"
            result = self.tools[tool_name](user_prompt)
        else:
            result = "Direct LLM Response"

        self.state.append({"role": "assistant", "content": result})
        return result

agent_system = AutonomousAgent()
agent_output = agent_system.run("Please search for agentic safety guidelines")
print("Agent Final Response:\n", agent_output)

3. Why should exponential backoff always incorporate random "jitter" when retrying rate-limited LLM API calls?
  • Jitter encrypts the API request payload against eavesdropping.
  • To prevent the "thundering herd" problem where synchronized client retries repeatedly overwhelm the API provider at the exact same second.
  • To reduce Python memory consumption during sleep.
  • Jitter is required by the HTTP 1.1 specification.

9. What is the fundamental operational difference between time.sleep(5) and await asyncio.sleep(5)?
