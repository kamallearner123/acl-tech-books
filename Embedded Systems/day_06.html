6.1 Bridging the Analog Real-World and Digital Computing

The physical physical universe is analog: temperatures shift smoothly, pressures fluctuate continuously, sound waves propagate as subtle voltage changes, and battery chemistry drains across gradual decay curves. Digital microcontrollers, however, compute strictly in discrete binary bits ($0$ and $1$). The Analog-to-Digital Converter (ADC) and Digital-to-Analog Converter (DAC) form the fundamental electronic sensory organs and physical vocal cords of embedded computing.

Real World Example: In an intensive care unit (ICU) patient pulse oximeter, an optical photodiode detects minute fluctuations in infrared light transmission through capillary blood vessels. A 12-bit SAR ADC samples this microvolt signal at 500 Hz, applying digital filtering to extract arterial blood oxygen saturation ($SpO_2$) and heart rate with medical-grade accuracy.
Figure 1.5-1: Successive Approximation Register (SAR) ADC Internal Silicon Architecture
Figure Parameters Explained:
  • Sample & Hold Stage: Samples input voltage onto internal holding capacitor during programmed sampling time, keeping voltage stable during conversion.
  • Comparator: Compares held analog voltage against the internal DAC output voltage.
  • Binary Search Logic: Tests bits from MSB to LSB. If V_in > V_dac, bit remains 1; otherwise, bit is cleared to 0.
  • Conversion Latency: Total time = Sampling Cycles + Conversion Cycles (typically 12 cycles for 12-bit resolution).

6.2 ADC Resolution, Reference Voltage, and Quantization Error

An ADC digitizes an analog voltage by mapping continuous voltages into $2^N$ discrete digital numbers, where $N$ is the converter's Bit Resolution. The voltage span represented by the Least Significant Bit ($1\text{ LSB}$) is defined by the Reference Voltage ($V_{REF}$):

$$1\text{ LSB} = \frac{V_{REF+}}{2^N - 1}$$

For a 12-bit ADC powered with $V_{REF+} = 3.30\text{ V}$, $1\text{ LSB} = \frac{3.30\text{ V}}{4095} \approx 0.8058\text{ mV}$. Any analog voltage between two discrete quantization steps incurs a rounding discrepancy known as Quantization Error (bounded theoretically by $\pm 0.5\text{ LSB}$).

Figure 1.5-2: ADC Quantization Staircase Transfer Function and Quantization Noise
Figure Parameters Explained:
  • Full-Scale Voltage (V_REF): The maximum measurable analog voltage corresponding to digital code 0xFFF (4095).
  • 1 LSB Step: The minimum voltage change detectable by the digital converter (0.806 mV at 3.3V / 12-bit).
  • Quantization Noise: Inherent statistical noise caused by discrete rounding; theoretical SNR = 6.02 * N + 1.76 dB (approx 74 dB for 12-bit ADC).
  • Integral Non-Linearity (INL): Maximum deviation of the actual transfer curve from the ideal line, measured in LSBs.

6.3 Sensor Signal Conditioning: Voltage Dividers & The Steinhart-Hart Equation

Most environmental sensors (such as thermistors, photoresistors, and strain gauges) do not output a clean, buffered voltage. A Negative Temperature Coefficient (NTC) Thermistor varies its electrical resistance non-linearly with temperature. To measure resistance using an ADC, engineers place the thermistor in a Voltage Divider circuit with a precision fixed resistor ($R_{fixed}$).

The resulting voltage is converted to accurate temperature using the empirical Steinhart-Hart Equation (or its simplified Beta formula):

$$\frac{1}{T} = \frac{1}{T_0} + \frac{1}{\beta} \ln\left(\frac{R_{NTC}}{R_0}\right)$$

Figure 1.5-3: NTC Thermistor Signal Conditioning Voltage Divider Circuit
Figure Parameters Explained:
  • Voltage Divider Formula: V_out = V_DD * (R_NTC / (R_fixed + R_NTC)). Solved in firmware to extract R_NTC dynamically.
  • Anti-Aliasing Filter: Low-pass RC filter removes high-frequency electromagnetic noise above the Nyquist frequency before sampling.
  • Input Impedance Match: STM32 SAR ADCs require source impedance R_in < 10k ohm to fully charge internal sampling capacitors within the programmed sampling window.
  • Self-Heating Effect: Current passing through the thermistor dissipates power (I^2 * R), artificially raising temperature if fixed resistor value is too small.

6.4 Multi-Channel Scanning and DMA Autonomous Data Streaming

Sampling multiple analog sensors via software polling wastes hundreds of microseconds of CPU time waiting for conversion flags. Modern microcontrollers configure the ADC in Scan Mode coupled with a Direct Memory Access (DMA) controller. A hardware timer triggers the ADC periodically; the ADC automatically converts channels 0 through 7 sequentially, and the DMA controller transfers each result directly into an SRAM array with zero CPU intervention.

Figure 1.5-4: Autonomous ADC Multi-Channel Scan and DMA Transfer Pipeline
Figure Parameters Explained:
  • Regular Channel Sequence: Configurable hardware sequencer (ADC_SQR1-SQR3) defining conversion order across arbitrary analog pins.
  • DMA Circular Mode: Continuously streams sensor data to RAM in an infinite ring buffer without CPU re-arming.
  • Zero CPU Overhead: The CPU remains in deep sleep or executes application algorithms while hardware acquires sensor telemetry.
  • Half-Transfer Interrupt: Signals that the first half of the DMA buffer is ready for processing while hardware fills the second half.

6.5 Digital-to-Analog Conversion (DAC) & Waveform Synthesis

The Digital-to-Analog Converter (DAC) executes the inverse of the ADC: it transforms 12-bit digital values into an authentic, continuous physical voltage on an output pin. Unlike PWM, which outputs a square wave that requires heavy low-pass filtering, a DAC produces genuine DC voltage levels capable of generating pure analog audio, servo reference voltages, or biomedical test signals.

Figure 1.5-5: DAC Sine Wave Synthesis with Timer Trigger and DMA
Figure Parameters Explained:
  • DAC Data Holding Register (DHR): Buffers 12-bit digital words before transferring to the active DAC output register.
  • Reconstruction Low-Pass Filter: Removes high-frequency image harmonics produced by discrete DAC voltage steps.
  • Output Buffer: Internal operational amplifier buffering DAC output to drive low-impedance external loads without sagging.
  • Settling Time: Time required for the DAC output voltage to settle within +/- 0.5 LSB of target (typically 3 to 6 microseconds on STM32).

#include <stdint.h>

#define RCC_AHB1ENR     (*(volatile uint32_t *)0x40023830UL)
#define RCC_APB2ENR     (*(volatile uint32_t *)0x40023844UL)

#define GPIOA_MODER     (*(volatile uint32_t *)0x40020000UL)

#define ADC1_BASE       0x40012000UL
#define ADC1_SR         (*(volatile uint32_t *)(ADC1_BASE + 0x00UL))
#define ADC1_CR1        (*(volatile uint32_t *)(ADC1_BASE + 0x04UL))
#define ADC1_CR2        (*(volatile uint32_t *)(ADC1_BASE + 0x08UL))
#define ADC1_SMPR2      (*(volatile uint32_t *)(ADC1_BASE + 0x10UL))
#define ADC1_SQR3       (*(volatile uint32_t *)(ADC1_BASE + 0x34UL))
#define ADC1_DR         (*(volatile uint32_t *)(ADC1_BASE + 0x4CUL))

void adc1_init_pa0(void) {
    /* 1. Enable clocks for GPIOA and ADC1 */
    RCC_AHB1ENR |= (1UL << 0);
    RCC_APB2ENR |= (1UL << 8);

    /* 2. Configure PA0 as Analog Mode (MODER0 = 0b11) */
    GPIOA_MODER |= (3UL << 0);

    /* 3. Set Sample Time for Channel 0 to 84 cycles (SMPR2 bits [2:0] = 0b100) */
    ADC1_SMPR2 |= (4UL << 0);

    /* 4. Sequence 1st conversion: Channel 0 (SQR3 bits [4:0] = 0) */
    ADC1_SQR3 &= ~0x1FUL;

    /* 5. Enable ADC peripheral (ADON = 1) */
    ADC1_CR2 |= (1UL << 0);
}

uint16_t adc1_read_single(void) {
    /* Start conversion by setting SWSTART bit in CR2 */
    ADC1_CR2 |= (1UL << 30);

    /* Poll End-of-Conversion (EOC) flag in SR */
    while (!(ADC1_SR & (1UL << 1))) {
        /* Busy wait */
    }

    /* Reading DR automatically clears EOC flag */
    return (uint16_t)(ADC1_DR & 0x0FFFUL);
}
Program 1.5-1: Single-Channel Polled ADC Reading on PA0 (ADC1_IN0) 

#include <stdint.h>
#include <math.h>

#define V_REF           3.30f       /* Volts */
#define R_FIXED         10000.0f    /* 10k ohm precision pull-up */
#define BETA            3950.0f     /* NTC Beta parameter (Kelvin) */
#define T0_KELVIN       298.15f     /* 25.0 degrees Celsius in Kelvin */
#define R0_THERMISTOR   10000.0f    /* 10k ohm at 25C */

float calculate_temperature_celsius(uint16_t raw_adc) {
    if (raw_adc == 0 || raw_adc >= 4095) return -999.0f; /* Fault */

    /* 1. Convert digital code to analog voltage */
    float v_out = ((float)raw_adc / 4095.0f) * V_REF;

    /* 2. Compute NTC resistance from voltage divider: V_out = V_DD * (R_NTC / (R_FIXED + R_NTC)) */
    float r_ntc = R_FIXED * (v_out / (V_REF - v_out));

    /* 3. Apply Steinhart-Hart Beta formula */
    float inv_t = (1.0f / T0_KELVIN) + (1.0f / BETA) * logf(r_ntc / R0_THERMISTOR);
    float temp_kelvin = 1.0f / inv_t;

    return temp_kelvin - 273.15f; /* Convert Kelvin to Celsius */
}

Program 1.5-4: DAC Sine Wave Synthesis via Timer TRGO and DMA 

#include <stdint.h>

/* Oversample 16 readings to gain 2 bits of effective resolution (12-bit -> 14-bit)
 * Formula: Oversampling Factor M = 4^k, where k is desired extra bits.
 * For 2 extra bits: M = 4^2 = 16 samples.
 * Resulting sum is right-shifted by k = 2 bits.
 */
uint16_t adc_read_oversampled_14bit(void) {
    uint32_t accumulator = 0;
    
    for (int i = 0; i < 16; i++) {
        /* In real systems, add small analog white dither noise */
        accumulator += adc1_read_single();
    }
    
    /* Decimation: Right shift accumulator by 2 bits */
    return (uint16_t)(accumulator >> 2);
}

Topic Quiz (10 Questions)

Test your conceptual understanding of today's embedded systems architecture, registers, and runtime behaviors.

1. What is the voltage value of 1 LSB for a 12-bit ADC with a Reference Voltage (VREF+) of 3.30 V?
  • 0.806 mV
  • 3.22 mV
  • 12.89 mV
  • 0.100 mV
1 LSB = 3.30 V / (2^12 - 1) = 3.30 V / 4095 ≈ 0.8058 mV (approx 0.806 mV).
2. How many clock cycles does a Successive Approximation Register (SAR) ADC require to complete a 12-bit conversion (excluding sampling time)?
  • 1 cycle
  • 12 cycles
  • 4096 cycles
  • 64 cycles
A SAR ADC resolves 1 bit per conversion clock cycle using a binary search algorithm. A 12-bit SAR ADC requires exactly 12 conversion clock cycles.
3. According to the Nyquist-Shannon sampling theorem, what is the minimum sampling frequency required to digitize an analog signal containing frequencies up to 4 kHz without aliasing?
  • 2 kHz
  • 4 kHz
  • 8 kHz
  • 16 kHz
The Nyquist criterion states that the sampling rate must be strictly greater than twice the highest frequency component (f_sample >= 2 * f_max = 8 kHz).
4. What is the role of an anti-aliasing low-pass RC filter placed in front of an ADC input pin?
  • To amplify microvolt signals
  • To attenuate frequencies above the Nyquist limit, preventing high-frequency noise from folding back into the digitized signal
  • To double the effective clock frequency
  • To provide galvanic isolation
Frequencies above half the sample rate reflect back into the measurement band as false low-frequency aliases unless eliminated by an analog low-pass filter.
5. To gain 2 additional bits of effective resolution (ENOB) via software oversampling and decimation, how many raw ADC samples must be accumulated?
  • 4 samples
  • 8 samples
  • 16 samples (4^2)
  • 64 samples
Oversampling requires M = 4^k samples, where k is the number of desired extra bits. For k = 2 bits, M = 4^2 = 16 samples.
6. Why is combining ADC Scan Mode with a DMA controller preferred over polling in multi-channel sensor acquisition?
  • DMA eliminates the need for reference voltages
  • DMA moves converted sensor words into SRAM autonomously without burning CPU cycles
  • DMA converts analog signals directly to floating point numbers
  • DMA doubles the sampling speed of silicon
DMA offloads memory transfer from the processor core, allowing multiple channels to be digitized and stored in RAM while the CPU sleeps.
7. What mathematical relationship describes the resistance variation of an NTC thermistor across temperature?
  • Ohm's Linear Law
  • The Steinhart-Hart / Beta Equation
  • Coulomb's Law
  • Faraday's Induction Equation
NTC thermistors exhibit a logarithmic, non-linear resistance decay modeled accurately by the Steinhart-Hart equation or its Beta parameter approximation.
8. What happens if the external source impedance driving an STM32 SAR ADC input pin is too high (> 50k ohm)?
  • The microcontroller resets
  • The internal sampling capacitor cannot charge fully during the sampling window, causing inaccurate, sagging readings
  • The ADC clock stops running
  • The flash memory becomes corrupted
The internal sampling switch connects an internal holding capacitor (~5-10 pF). If source resistance is too high, the RC time constant exceeds the sampling window.
9. What is the primary difference between a true DAC output and a filtered PWM output?
  • A true DAC produces a genuine, low-ripple continuous analog voltage level without high-frequency switching noise
  • A true DAC can only output AC square waves
  • Filtered PWM requires less CPU power than a DAC
  • DAC outputs cannot drive analog circuits
A true DAC uses an internal R-2R ladder or resistor string to generate pure DC voltage levels, avoiding the ripple and slow response of PWM filters.
10. In STM32 microcontrollers, which hardware peripheral event can automatically trigger the start of an ADC conversion without CPU software intervention?
  • Watchdog timeout
  • Timer TRGO (Trigger Output) event
  • Flash wait-state change
  • Brown-out reset
Timer TRGO outputs can be routed internally to trigger ADC conversions synchronously at deterministic sample rates.
