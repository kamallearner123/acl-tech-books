7.1 Serial Communication in Embedded Systems

Microcontrollers cannot operate in isolation: they must stream telemetry to host computers, interrogate environmental sensor arrays, display graphics on LCD screens, and exchange packets with wireless modems. The three canonical embedded serial protocols are UART (Universal Asynchronous Receiver/Transmitter), SPI (Serial Peripheral Interface), and I2C (Inter-Integrated Circuit). Each protocol resolves trade-offs between wire count, transmission speed, bus topology, and silicon complexity.

Real World Example: In a modern quadcopter drone, the STM32 flight controller communicates simultaneously across all three buses: UART streams GPS NMEA coordinates and telemetries to the radio link at 115200 baud; SPI samples a 6-axis IMU gyro/accelerometer at 8 MHz for sub-millisecond PID stabilization; and I2C reads an external magnetic compass and barometric altimeter at 400 kHz over a shared 2-wire bus.
Figure 1.6-1: UART Asynchronous Frame Structure and Timing
Figure Parameters Explained:
  • Start Bit (Logic 0): Signals receiver hardware to synchronize its internal clock counter to the incoming frame.
  • Baud Rate Formula: Bit Duration = 1 / Baud Rate. At 115200 baud, each bit lasts exactly 8.68 microseconds.
  • Oversampling Receiver: Receivers sample each incoming bit 8x or 16x per bit period, taking majority votes at sample counts 7, 8, and 9 to reject line noise.
  • Clock Drift Tolerance: Asynchronous framing requires sender and receiver crystal clocks to match within +/- 2.5% to avoid bit slip errors.

7.2 SPI: Synchronous 4-Wire Master-Slave Protocol

SPI (Serial Peripheral Interface) is a high-speed, full-duplex, synchronous serial bus developed by Motorola. It utilizes four physical lines:

  • SCLK (Serial Clock): Driven exclusively by the Master device.
  • MOSI (Master Out, Slave In): Data transmission from Master to Slave.
  • MISO (Master In, Slave Out): Data transmission from Slave to Master.
  • CS / SS (Chip Select / Slave Select): Active-LOW line asserted by Master to address a specific slave on the bus.

SPI clocking is governed by two parameters: CPOL (Clock Polarity) and CPHA (Clock Phase), forming 4 distinct operating modes (Mode 0 through Mode 3).

Figure 1.6-2: SPI 4-Wire Topology and CPOL / CPHA Clock Timing Modes
Figure Parameters Explained:
  • CPOL = 0 / 1: Defines idle clock level: 0 = SCLK idles LOW; 1 = SCLK idles HIGH.
  • CPHA = 0 / 1: Defines capture edge: 0 = data sampled on first clock transition; 1 = data sampled on second transition.
  • High Throughput: SPI easily achieves 20 MHz to 80 MHz clock speeds, making it ideal for SPI Flash, SD cards, and TFT displays.
  • Independent Chip Selects: Adding multiple slaves requires a dedicated GPIO CS line per slave device.

7.3 I2C: Synchronous 2-Wire Multi-Device Bus with Open-Drain Architecture

Invented by Philips (now NXP), I2C (Inter-Integrated Circuit) reduces bus wiring to just two lines: SDA (Serial Data) and SCL (Serial Clock). Both lines operate in Open-Drain mode with external pull-up resistors to VDD. Key I2C protocol rules include:

  • START Condition: SDA transitions HIGH to LOW while SCL remains HIGH.
  • STOP Condition: SDA transitions LOW to HIGH while SCL remains HIGH.
  • Data Validity: SDA must remain stable while SCL is HIGH; SDA may only change when SCL is LOW.
  • ACK / NACK: Following every 8-bit byte transfer, the receiving device must pull SDA LOW during the 9th clock pulse to acknowledge receipt (ACK).
  • 7-Bit Device Addressing: The first byte transmitted by the Master contains the 7-bit slave address and bit 0 indicating Read ($1$) or Write ($0$).
Figure 1.6-3: I2C Bus Electrical Architecture and Packet Protocol Frame
Figure Parameters Explained:
  • Open-Drain + Pull-Ups: Enables wired-AND bus arbitration without short circuits when multiple nodes pull lines LOW.
  • ACK (Logic 0): Receiver pulls SDA LOW during 9th clock to confirm byte reception.
  • NACK (Logic 1): SDA remains HIGH (released to pull-up), signaling byte rejection or end of multi-byte read.
  • Bus Speed Grades: Standard Mode (100 kbps), Fast Mode (400 kbps), Fast Mode Plus (1 Mbps), High Speed (3.4 Mbps).

7.4 I2C Multi-Master Arbitration and Clock Stretching

Because I2C pins are open-drain, multiple master devices can share the same bus. When two masters transmit simultaneously, Non-Destructive Bus Arbitration occurs: both monitor SDA while transmitting. The first master attempting to send a 1 that reads back a 0 (because the other master drove a dominant 0) immediately detects that it lost arbitration, gracefully yielding the bus without corrupting the winning master's frame.

Additionally, slow slave devices can execute Clock Stretching by holding the SCL line LOW, temporarily pausing the master until the slave finishes internal processing.

Figure 1.6-4: I2C Multi-Master Bus Arbitration on Open-Drain SDA Line
Figure Parameters Explained:
  • Dominant State (0): Actively driven to ground by internal N-MOS transistor; overrides recessive state.
  • Recessive State (1): Line pulled HIGH by external resistor; can be pulled down by any other connected device.
  • Clock Stretching: Slave pulls SCL LOW to insert hardware wait-states while preparing data.
  • Bus Lockup Condition: If a slave crashes while pulling SDA LOW, the bus hangs; masters must toggle SCL 9 times to force a reset.

7.5 High-Throughput Serial Communication with DMA & printf Retargeting

Transmitting a 128-byte log message over UART at 115200 baud via software polling takes approximately 11 milliseconds—equivalent to nearly 2 million lost CPU cycles on a 168 MHz processor. By retargeting standard C library printf() functions through a circular UART DMA Controller, the processor initiates transmission in a single cycle and continues executing application tasks while DMA hardware streams bytes out the serial port.

Figure 1.6-5: UART DMA Streaming Pipeline vs. Polling Overhead
Figure Parameters Explained:
  • USART_DR to Memory DMA: Transfers bytes from RAM to transmit data register automatically as TXE flags assert.
  • Retargeting _write(): Newlib syscall hook that intercepts standard C library printf() and routes characters to UART.
  • Transfer Complete (TC) ISR: Fires only when the entire multi-byte buffer has completely cleared the UART shift register.

#include <stdint.h>

#define RCC_AHB1ENR     (*(volatile uint32_t *)0x40023830UL)
#define RCC_APB1ENR     (*(volatile uint32_t *)0x40023840UL)

#define GPIOA_MODER     (*(volatile uint32_t *)0x40020000UL)
#define GPIOA_AFRL      (*(volatile uint32_t *)0x40020020UL)

#define USART2_BASE     0x40004400UL
#define USART2_SR       (*(volatile uint32_t *)(USART2_BASE + 0x00UL))
#define USART2_DR       (*(volatile uint32_t *)(USART2_BASE + 0x04UL))
#define USART2_BRR      (*(volatile uint32_t *)(USART2_BASE + 0x08UL))
#define USART2_CR1      (*(volatile uint32_t *)(USART2_BASE + 0x0CUL))

/* Initialize USART2 on PA2 (TX) at 115200 baud (assuming 16 MHz APB1 clock) */
void usart2_init_115200(void) {
    /* 1. Enable clocks for GPIOA and USART2 */
    RCC_AHB1ENR |= (1UL << 0);
    RCC_APB1ENR |= (1UL << 17);

    /* 2. Configure PA2 as Alternate Function AF7 (MODER2 = 0b10) */
    GPIOA_MODER &= ~(3UL << 4);
    GPIOA_MODER |= (2UL << 4);
    GPIOA_AFRL &= ~(0xFUL << 8);
    GPIOA_AFRL |= (0x7UL << 8); /* AF7 = USART2_TX */

    /* 3. Configure Baud Rate: BRR = 16,000,000 / (16 * 115200) = 8.6805
          Mantissa = 8, Fraction = 0.6805 * 16 = 11 (0x8B) */
    USART2_BRR = 0x008B;

    /* 4. Enable Transmitter (TE) and USART peripheral (UE) */
    USART2_CR1 |= (1UL << 3) | (1UL << 13);
}

void uart2_send_char(char c) {
    /* Wait until Transmit Data Register Empty (TXE) flag is set */
    while (!(USART2_SR & (1UL << 7))) {
        /* Wait */
    }
    USART2_DR = (uint32_t)c;
}

void uart2_send_string(const char *str) {
    while (*str) {
        uart2_send_char(*str++);
    }
}

#include <stdint.h>

#define SPI1_BASE       0x40013000UL
#define SPI1_CR1        (*(volatile uint32_t *)(SPI1_BASE + 0x00UL))
#define SPI1_SR         (*(volatile uint32_t *)(SPI1_BASE + 0x08UL))
#define SPI1_DR         (*(volatile uint32_t *)(SPI1_BASE + 0x0CUL))

#define GPIOA_BSRR      (*(volatile uint32_t *)0x40020018UL)
#define CS_PIN          4 /* PA4 as Software Chip Select */

static inline void spi_cs_low(void)  { GPIOA_BSRR = (1UL << (CS_PIN + 16)); }
static inline void spi_cs_high(void) { GPIOA_BSRR = (1UL << CS_PIN); }

uint8_t spi1_transfer(uint8_t tx_data) {
    /* Wait until TX buffer empty (TXE) */
    while (!(SPI1_SR & (1UL << 1)));
    SPI1_DR = tx_data;

    /* Wait until RX buffer full (RXNE) */
    while (!(SPI1_SR & (1UL << 0)));
    return (uint8_t)SPI1_DR;
}

/* Read 3-byte JEDEC Manufacturer and Device ID (0x9F command) */
uint32_t read_flash_jedec_id(void) {
    spi_cs_low();
    
    spi1_transfer(0x9F); /* JEDEC ID command */
    uint8_t mfg_id  = spi1_transfer(0x00); /* Manufacturer (0xEF for Winbond) */
    uint8_t mem_type = spi1_transfer(0x00); /* Memory Type */
    uint8_t capacity = spi1_transfer(0x00); /* Capacity (0x16 for 32Mb / 4MB) */
    
    spi_cs_high();
    
    return ((uint32_t)mfg_id << 16) | ((uint32_t)mem_type << 8) | capacity;
}

#include <stdint.h>
#include <stdbool.h>

#define I2C1_BASE       0x40005400UL
#define I2C1_CR1        (*(volatile uint32_t *)(I2C1_BASE + 0x00UL))
#define I2C1_CR2        (*(volatile uint32_t *)(I2C1_BASE + 0x04UL))
#define I2C1_DR         (*(volatile uint32_t *)(I2C1_BASE + 0x10UL))
#define I2C1_SR1        (*(volatile uint32_t *)(I2C1_BASE + 0x14UL))
#define I2C1_SR2        (*(volatile uint32_t *)(I2C1_BASE + 0x18UL))

#define BMP280_I2C_ADDR 0x76 /* 7-bit slave address */

/* Read single register from I2C slave */
uint8_t i2c_read_reg(uint8_t dev_addr, uint8_t reg_addr) {
    /* 1. Generate START condition */
    I2C1_CR1 |= (1UL << 8);
    while (!(I2C1_SR1 & (1UL << 0))); /* Wait for SB flag */

    /* 2. Send 7-bit Address with Write bit (0) */
    I2C1_DR = (dev_addr << 1);
    while (!(I2C1_SR1 & (1UL << 1))); /* Wait for ADDR flag */
    (void)I2C1_SR2; /* Clear ADDR by reading SR2 */

    /* 3. Send target register address */
    I2C1_DR = reg_addr;
    while (!(I2C1_SR1 & (1UL << 2))); /* Wait for BTF (Byte Transfer Finished) */

    /* 4. Repeated START for read */
    I2C1_CR1 |= (1UL << 8);
    while (!(I2C1_SR1 & (1UL << 0)));

    /* 5. Send 7-bit Address with Read bit (1) */
    I2C1_DR = (dev_addr << 1) | 1;
    while (!(I2C1_SR1 & (1UL << 1)));
    
    /* Disable ACK before reading single byte, generate STOP */
    I2C1_CR1 &= ~(1UL << 10);
    (void)I2C1_SR2;
    I2C1_CR1 |= (1UL << 9); /* STOP */

    while (!(I2C1_SR1 & (1UL << 6))); /* Wait for RXNE */
    return (uint8_t)I2C1_DR;
}
Program 1.6-4: I2C Sensor Interface: Reading BMP280 Barometer Chip ID 

#include <stdint.h>

#define DMA1_STREAM6_BASE   0x400260A0UL
#define DMA_SxCR(base)      (*(volatile uint32_t *)(base + 0x00UL))
#define DMA_SxNDTR(base)    (*(volatile uint32_t *)(base + 0x04UL))
#define DMA_SxPAR(base)     (*(volatile uint32_t *)(base + 0x08UL))
#define DMA_SxM0AR(base)    (*(volatile uint32_t *)(base + 0x0CUL))

void uart2_dma_transmit(const uint8_t *data, uint16_t length) {
    /* 1. Disable DMA stream to allow configuration */
    DMA_SxCR(DMA1_STREAM6_BASE) &= ~(1UL << 0);
    while (DMA_SxCR(DMA1_STREAM6_BASE) & (1UL << 0));

    /* 2. Set peripheral address to USART2->DR */
    DMA_SxPAR(DMA1_STREAM6_BASE) = 0x40004404UL;

    /* 3. Set memory buffer address and transfer length */
    DMA_SxM0AR(DMA1_STREAM6_BASE) = (uint32_t)data;
    DMA_SxNDTR(DMA1_STREAM6_BASE) = length;

    /* 4. Configure DMA: Channel 4, Memory Increment, Memory-to-Peripheral, TC Interrupt */
    DMA_SxCR(DMA1_STREAM6_BASE) = (4UL << 25) | (1UL << 10) | (1UL << 6) | (1UL << 4);

    /* 5. Enable DMA stream to begin transmission */
    DMA_SxCR(DMA1_STREAM6_BASE) |= (1UL << 0);
}

Topic Quiz (10 Questions)

Test your conceptual understanding of today's embedded systems architecture, registers, and runtime behaviors.

1. What is the primary function of the Start bit (Logic 0) in an asynchronous UART data frame?
  • To charge the receiver decoupling capacitors
  • To synchronize the receiver's internal bit-sampling clock to the incoming frame
  • To transmit the device hardware address
  • To clear the parity error flag
Because UART has no shared clock wire, the falling edge of the Start bit alerts the receiver to synchronize its oversampling timer.
2. In SPI communication, what does the configuration `CPOL = 0, CPHA = 1` define?
  • Clock idles LOW, data is captured on the second (falling) clock edge
  • Clock idles HIGH, data is captured on the first clock edge
  • Clock idles LOW, data is captured on the first (rising) clock edge
  • Clock idles HIGH, data is captured on the second clock edge
CPOL=0 means SCLK idles LOW. CPHA=1 specifies that data is sampled on the second clock transition (falling edge).
3. Why are external pull-up resistors mandatory on I2C SDA and SCL bus lines?
  • To protect against electrostatic discharge (ESD)
  • Because I2C pins operate in Open-Drain mode and can only pull the lines LOW, requiring resistors to pull HIGH
  • To step down 5V signals to 3.3V
  • To prevent high-frequency reflections on long cables
I2C drivers are open-drain (N-MOS only). They pull lines to ground (0) or float (Hi-Z). External pull-ups are required to pull lines to VDD (1).
4. How does an I2C slave acknowledge successful reception of an 8-bit data byte from the master?
  • By transmitting an ASCII 'OK' string
  • By pulling the SDA line LOW (ACK) during the 9th SCL clock pulse
  • By holding SCL LOW for 5 milliseconds
  • By asserting an external interrupt pin
During the 9th clock cycle, the master releases SDA and the receiver pulls SDA LOW to indicate ACK (0 = ACK, 1 = NACK).
5. What occurs during I2C multi-master arbitration if Master A transmits a 1 while Master B transmits a 0 on SDA?
  • A short-circuit condition destroys both transmitters
  • Master B drives the line LOW; Master A detects the collision, yields the bus, and Master B continues without error
  • The bus controller asserts a HardFault on both processors
  • Both masters immediately abort transmission and generate STOP conditions
In wired-AND open-drain logic, 0 dominates 1. Master A sees that it attempted to output a 1 but the line remained 0, detecting arbitration loss gracefully.
6. What is 'Clock Stretching' in the I2C protocol specification?
  • A method of overclocking the bus to 10 Mbps
  • An action where a slow slave pulls SCL LOW to pause the master while it processes data
  • A technique to reduce power by lowering the master PLL clock
  • An error condition caused by missing pull-up resistors
If a slave cannot keep up with master clocking, it holds SCL LOW. The master senses this and waits until the slave releases SCL before continuing.
7. Why is using UART with DMA vastly superior to polling for sending telemetry strings?
  • DMA automatically encrypts data packets
  • DMA transfers data from memory to the UART register autonomously, leaving 100% of CPU cycles free for other tasks
  • DMA doubles the baud rate of the UART transmitter
  • DMA eliminates the need for Start and Stop bits
Polling wastes millions of CPU cycles waiting for TXE flags. DMA streams entire buffers byte-by-byte in hardware without CPU involvement.
8. Which system call function in Newlib C library must be implemented to retarget `printf()` to a UART serial port?
  • _read()
  • _write()
  • _sbrk()
  • _exit()
Standard C runtime implementations route stdout through the low-level `_write(int fd, char *buf, int len)` syscall hook.
9. What is the standard JEDEC instruction byte sent over SPI to read manufacturer and memory density information from an SPI Flash chip?
  • 0x06 (Write Enable)
  • 0x03 (Read Data)
  • 0x9F (Read JEDEC ID)
  • 0xC7 (Chip Erase)
The JEDEC standard command 0x9F prompts all compliant SPI NOR flash devices (Winbond, Macronix, Micron) to return manufacturer, type, and capacity bytes.
10. If an I2C slave becomes desynchronized and locks the SDA line LOW indefinitely, how can the master recover the bus?
  • By generating an immediate STOP condition
  • By clocking the SCL line manually 9 times to force the slave to release SDA, then issuing a STOP condition
  • By shorting VDD to ground
  • By increasing the pull-up resistor values
Manually pulsing SCL up to 9 times gives the stuck slave enough clocks to finish sending its pending byte and release SDA.

Complete these 5 lab assignments to solidify your hands-on firmware engineering skills.

Assignment 1: Interactive UART Command-Line Shell Interpreter

Task: Build a responsive CLI over UART at 115200 baud. Implement an input line buffer parsing commands: 'led on', 'led off', 'temp', and 'status'. Handle backspaces and newline formatting gracefully.

Assignment 2: Automatic 7-Bit I2C Bus Address Scanner

Task: Write an I2C scanner that queries all 128 valid 7-bit addresses (0x00 to 0x7F). Check for slave ACK responses and print a formatted ASCII grid table of all detected peripherals to UART.

Assignment 3: SPI Flash Memory Identification and Sector Erase

Task: Connect a W25Q32 or similar SPI NOR flash. Write functions to read the 3-byte JEDEC ID, erase a 4 KB sector, program a 256-byte text string, and read it back to verify data retention across power cycles.

Assignment 4: Multi-Sensor BMP280 + MPU6050 Shared I2C Bus Driver

Task: Interface both a BMP280 pressure sensor (0x76) and an MPU-6050 accelerometer (0x68) on the exact same I2C bus pins. Read acceleration and barometric pressure alternately every 50 ms without bus collisions.

Assignment 5: UART RX DMA Circular Ring Buffer Engine

Task: Implement an asynchronous UART receiver using DMA in circular mode. Detect incoming line boundaries without polling using the UART Idle Line Detection (IDLE) interrupt to trigger packet parsing.
