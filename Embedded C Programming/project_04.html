Module 4 Capstone Project

Standards, State Machines & Defensive Systems

Writing firmware for life-critical or industrial equipment requires disciplined engineering practices. Ad-hoc spaghetti code with nested if/else chains fails in edge cases and cannot be certified under standards such as MISRA-C or ISO 26262. In this milestone, we construct two robust systems: a MISRA-C compliant, table-driven Access Control FSM tested via automated GDB scripts on Linux/WSL, and a Safety-Critical Motor Controller featuring an Independent Hardware Watchdog (IWDG) and custom HardFault diagnostic capture on STM32.

Project Focus MISRA-C Table-Driven Access Control FSM & GDB Suite Safety-Critical Motor Controller with IWDG & HardFault Trap
Design Pattern 2D State Transition Matrix with action function pointers Hierarchical FSM with fail-safe fallback & watchdog supervision

Part 1: Linux / WSL Project — MISRA-C Compliant Access Control FSM

In security and industrial automation, access gates must never enter undefined states. A 2D State Transition Table guarantees deterministic $O(1)$ event dispatch, mathematically proves that all state-event permutations are handled, and eliminates deeply nested conditional logic.

System State Diagram & Transitions

[STATE_LOCKED] --------(EVENT_BADGE_SCANNED)-------> [STATE_AUTHENTICATING] ^ | | +---------------+---------------+ | | (AUTH_SUCCESS) | (AUTH_FAIL / 3x) | v v (TIMEOUT / 5s) [STATE_UNLOCKED] [STATE_LOCKOUT] | | | +--------------------------------------+ (TAMPER_DETECTED) | v [STATE_ALARM]

Step 1: Doxygen-Documented FSM Interface (access_fsm.h)

/**
 * @file access_fsm.h
 * @brief MISRA-C Compliant Table-Driven Industrial Access Control FSM
 * @author Apt Computing Labs
 * @date 2026
 */
#ifndef ACCESS_FSM_H
#define ACCESS_FSM_H

#include <stdint.h>
#include <stdbool.h>

/**
 * @brief Access Control States (Exhaustive Enum)
 */
typedef enum {
    STATE_LOCKED = 0,
    STATE_AUTHENTICATING,
    STATE_UNLOCKED,
    STATE_LOCKOUT,
    STATE_ALARM,
    STATE_COUNT /* Sentinel */
} fsm_state_t;

/**
 * @brief Access Control Events
 */
typedef enum {
    EVENT_BADGE_SCANNED = 0,
    EVENT_AUTH_SUCCESS,
    EVENT_AUTH_FAIL,
    EVENT_UNLOCK_TIMEOUT,
    EVENT_TAMPER_DETECTED,
    EVENT_RESET_KEY,
    EVENT_COUNT /* Sentinel */
} fsm_event_t;

/**
 * @brief Forward declaration of FSM context structure
 */
typedef struct access_fsm access_fsm_t;

/**
 * @brief Action callback function pointer type
 */
typedef void (*fsm_action_t)(access_fsm_t *p_fsm);

/**
 * @brief Transition Table Entry: Defines Next State and Associated Action
 */
typedef struct {
    fsm_state_t  next_state;
    fsm_action_t action;
} transition_entry_t;

/**
 * @brief Access FSM Instance Context
 */
struct access_fsm {
    fsm_state_t current_state;
    uint32_t    failed_attempts;
    uint32_t    audit_log_counter;
};

/* API Prototypes */
void access_fsm_init(access_fsm_t *p_fsm);
void access_fsm_dispatch(access_fsm_t *p_fsm, fsm_event_t event);
fsm_state_t access_fsm_get_state(const access_fsm_t *p_fsm);

#endif /* ACCESS_FSM_H */

Step 2: Table-Driven Implementation (access_fsm.c)

/**
 * @file access_fsm.c
 * @brief Implementation adhering strictly to MISRA-C:2012 Rules
 */
#include <stdio.h>
#include "access_fsm.h"

/* Action Function Prototypes */
static void action_log_scan(access_fsm_t *p_fsm);
static void action_unlock_solenoid(access_fsm_t *p_fsm);
static void action_lock_solenoid(access_fsm_t *p_fsm);
static void action_register_fail(access_fsm_t *p_fsm);
static void action_sound_alarm(access_fsm_t *p_fsm);
static void action_reset_lockout(access_fsm_t *p_fsm);
static void action_ignore(access_fsm_t *p_fsm);

/* State Transition Matrix [Current State][Event] */
static const transition_entry_t g_transition_table[STATE_COUNT][EVENT_COUNT] = {
    [STATE_LOCKED] = {
        [EVENT_BADGE_SCANNED]   = { STATE_AUTHENTICATING, action_log_scan },
        [EVENT_TAMPER_DETECTED] = { STATE_ALARM,          action_sound_alarm },
        [EVENT_AUTH_SUCCESS]    = { STATE_LOCKED,         action_ignore },
        [EVENT_AUTH_FAIL]       = { STATE_LOCKED,         action_ignore },
        [EVENT_UNLOCK_TIMEOUT]  = { STATE_LOCKED,         action_ignore },
        [EVENT_RESET_KEY]       = { STATE_LOCKED,         action_ignore }
    },
    [STATE_AUTHENTICATING] = {
        [EVENT_AUTH_SUCCESS]    = { STATE_UNLOCKED,       action_unlock_solenoid },
        [EVENT_AUTH_FAIL]       = { STATE_LOCKED,         action_register_fail },
        [EVENT_TAMPER_DETECTED] = { STATE_ALARM,          action_sound_alarm },
        [EVENT_BADGE_SCANNED]   = { STATE_AUTHENTICATING, action_ignore },
        [EVENT_UNLOCK_TIMEOUT]  = { STATE_LOCKED,         action_lock_solenoid },
        [EVENT_RESET_KEY]       = { STATE_AUTHENTICATING, action_ignore }
    },
    [STATE_UNLOCKED] = {
        [EVENT_UNLOCK_TIMEOUT]  = { STATE_LOCKED,         action_lock_solenoid },
        [EVENT_TAMPER_DETECTED] = { STATE_ALARM,          action_sound_alarm },
        [EVENT_BADGE_SCANNED]   = { STATE_UNLOCKED,       action_ignore },
        [EVENT_AUTH_SUCCESS]    = { STATE_UNLOCKED,       action_ignore },
        [EVENT_AUTH_FAIL]       = { STATE_UNLOCKED,       action_ignore },
        [EVENT_RESET_KEY]       = { STATE_UNLOCKED,       action_ignore }
    },
    [STATE_LOCKOUT] = {
        [EVENT_RESET_KEY]       = { STATE_LOCKED,         action_reset_lockout },
        [EVENT_TAMPER_DETECTED] = { STATE_ALARM,          action_sound_alarm },
        [EVENT_BADGE_SCANNED]   = { STATE_LOCKOUT,        action_ignore },
        [EVENT_AUTH_SUCCESS]    = { STATE_LOCKOUT,        action_ignore },
        [EVENT_AUTH_FAIL]       = { STATE_LOCKOUT,        action_ignore },
        [EVENT_UNLOCK_TIMEOUT]  = { STATE_LOCKOUT,        action_ignore }
    },
    [STATE_ALARM] = {
        [EVENT_RESET_KEY]       = { STATE_LOCKED,         action_reset_lockout },
        [EVENT_BADGE_SCANNED]   = { STATE_ALARM,          action_ignore },
        [EVENT_AUTH_SUCCESS]    = { STATE_ALARM,          action_ignore },
        [EVENT_AUTH_FAIL]       = { STATE_ALARM,          action_ignore },
        [EVENT_UNLOCK_TIMEOUT]  = { STATE_ALARM,          action_ignore },
        [EVENT_TAMPER_DETECTED] = { STATE_ALARM,          action_ignore }
    }
};

void access_fsm_init(access_fsm_t *p_fsm) {
    if (p_fsm != NULL) {
        p_fsm->current_state = STATE_LOCKED;
        p_fsm->failed_attempts = 0U;
        p_fsm->audit_log_counter = 0U;
    }
}

void access_fsm_dispatch(access_fsm_t *p_fsm, fsm_event_t event) {
    if ((p_fsm == NULL) || (event >= EVENT_COUNT) || (p_fsm->current_state >= STATE_COUNT)) {
        return; /* Defensive boundary guard (MISRA-C Rule 14.4) */
    }

    const transition_entry_t *p_entry = &g_transition_table[p_fsm->current_state][event];

    /* Update State */
    p_fsm->current_state = p_entry->next_state;
    p_fsm->audit_log_counter++;

    /* Execute Action Callback */
    if (p_entry->action != NULL) {
        p_entry->action(p_fsm);
    }
}

fsm_state_t access_fsm_get_state(const access_fsm_t *p_fsm) {
    return (p_fsm != NULL) ? p_fsm->current_state : STATE_LOCKED;
}

static void action_log_scan(access_fsm_t *p_fsm) {
    printf("[FSM Action] Badge scanned. Validating credentials...\n");
}

static void action_unlock_solenoid(access_fsm_t *p_fsm) {
    p_fsm->failed_attempts = 0U;
    printf("[FSM Action] Access Granted! Door Solenoid ENERGIZED (Unlocked).\n");
}

static void action_lock_solenoid(access_fsm_t *p_fsm) {
    printf("[FSM Action] Door Solenoid DE-ENERGIZED (Locked).\n");
}

static void action_register_fail(access_fsm_t *p_fsm) {
    p_fsm->failed_attempts++;
    printf("[FSM Action] Auth Failed! Attempt %u / 3.\n", p_fsm->failed_attempts);
    if (p_fsm->failed_attempts >= 3U) {
        printf("[FSM Action] MAXIMUM FAILS EXCEEDED. Transitioning to LOCKOUT!\n");
        p_fsm->current_state = STATE_LOCKOUT;
    }
}

static void action_sound_alarm(access_fsm_t *p_fsm) {
    printf("[FSM Action] CRITICAL ALARM! Siren ON, Security Telemetry Dispatched!\n");
}

static void action_reset_lockout(access_fsm_t *p_fsm) {
    p_fsm->failed_attempts = 0U;
    printf("[FSM Action] Supervisor Key Reset. Returning to LOCKED state.\n");
}

static void action_ignore(access_fsm_t *p_fsm) {
    /* MISRA explicit no-op */
    (void)p_fsm;
}

Part 2: Physical STM32 Board Project — Hardware Watchdog (IWDG) & HardFault Diagnostics

In critical microcontroller systems, software can lock up due to cosmic rays, EMI, or unexpected race conditions. The Independent Watchdog (IWDG) runs on a dedicated internal low-speed oscillator (LSI @ 32kHz) and cannot be halted by software once started. If the firmware fails to kick the watchdog within its programmed timeout, the MCU undergoes a hardware reset.

Bare-Metal Implementation (safety_motor.c)

/**
 * @file safety_motor.c
 * @brief Safety-Critical Motor Controller with IWDG & HardFault Handler
 * Target: STM32F401RE Nucleo-64
 */
#include <stdint.h>
#include <stdbool.h>

/* Register Offsets */
#define RCC_CSR        (*(volatile uint32_t *)(0x40023874UL))
#define RCC_AHB1ENR    (*(volatile uint32_t *)(0x40023830UL))
#define GPIOA_MODER    (*(volatile uint32_t *)(0x40020000UL))
#define GPIOA_BSRR     (*(volatile uint32_t *)(0x40020018UL))
#define GPIOC_IDR      (*(volatile uint32_t *)(0x40020810UL))

/* Independent Watchdog (IWDG) Registers */
#define IWDG_KR        (*(volatile uint32_t *)(0x40003000UL))
#define IWDG_PR        (*(volatile uint32_t *)(0x40003004UL))
#define IWDG_RLR       (*(volatile uint32_t *)(0x40003008UL))
#define IWDG_SR        (*(volatile uint32_t *)(0x4000300CUL))

/* IWDG Magic Key Values */
#define IWDG_KEY_RELOAD     0xAAAAUL
#define IWDG_KEY_ENABLE     0xCCCCUL
#define IWDG_KEY_WRITE_EN   0x5555UL

/* Stack Frame captured during HardFault */
typedef struct {
    uint32_t r0;
    uint32_t r1;
    uint32_t r2;
    uint32_t r3;
    uint32_t r12;
    uint32_t lr;
    uint32_t pc;
    uint32_t psr;
} hardfault_stack_t;

volatile hardfault_stack_t g_crash_telemetry;

/* C Portion of HardFault Handler called from assembly */
void HardFault_Handler_C(hardfault_stack_t *p_stack) {
    g_crash_telemetry = *p_stack;

    /* Disable interrupts and enter fail-safe visual beacon */
    __asm volatile ("cpsid i" : : : "memory");

    while (1) {
        /* Rapid strobe indicating hardware fault */
        GPIOA_BSRR = (1UL << 5);
        for (volatile int i = 0; i < 50000; i++);
        GPIOA_BSRR = (1UL << (5 + 16));
        for (volatile int i = 0; i < 50000; i++);
    }
}

/* Assembly Trampoline to extract correct stack pointer (MSP vs PSP) */
__attribute__((naked)) void HardFault_Handler(void) {
    __asm volatile (
        "tst lr, #4\n"              /* Test EXC_RETURN bit 2 */
        "ite eq\n"
        "mrseq r0, msp\n"          /* If 0, stack was MSP */
        "mrsne r0, psp\n"          /* If 1, stack was PSP */
        "b HardFault_Handler_C\n"  /* Branch to C handler with stack pointer in R0 */
    );
}

/* Configure IWDG for ~500ms Timeout */
static void iwdg_init(void) {
    IWDG_KR = IWDG_KEY_ENABLE;   /* 1. Start IWDG Clock */
    IWDG_KR = IWDG_KEY_WRITE_EN; /* 2. Enable write access to PR and RLR */
    IWDG_PR = 0x04UL;            /* 3. Prescaler /64 (32kHz / 64 = 500 Hz clock) */
    IWDG_RLR = 250UL;            /* 4. 250 ticks @ 500Hz = 500 ms timeout */
    while (IWDG_SR != 0U) { /* Wait for registers to update */ }
    IWDG_KR = IWDG_KEY_RELOAD;   /* 5. Initial reload */
}

/* Kick / Refresh Watchdog */
static inline void iwdg_refresh(void) {
    IWDG_KR = IWDG_KEY_RELOAD;
}

int main(void) {
    RCC_AHB1ENR |= (1UL << 0) | (1UL << 2); /* Enable GPIOA & GPIOC */

    /* PA5 (LED) Output */
    GPIOA_MODER &= ~(3UL << 10);
    GPIOA_MODER |=  (1UL << 10);

    /* Check if system reset was caused by IWDG timeout */
    bool was_watchdog_reset = ((RCC_CSR & (1UL << 29)) != 0);
    RCC_CSR |= (1UL << 24); /* Clear reset flags */

    if (was_watchdog_reset) {
        /* Blink 5 fast pulses to inform operator of watchdog recovery */
        for (int i = 0; i < 5; i++) {
            GPIOA_BSRR = (1UL << 5);
            for (volatile int d = 0; d < 80000; d++);
            GPIOA_BSRR = (1UL << (5 + 16));
            for (volatile int d = 0; d < 80000; d++);
        }
    }

    iwdg_init();

    while (1) {
        /* Normal Superloop Operation: Kick the watchdog */
        iwdg_refresh();

        /* Normal Heartbeat Toggle */
        GPIOA_BSRR = (1UL << 5);
        for (volatile int d = 0; d < 200000; d++);
        GPIOA_BSRR = (1UL << (5 + 16));
        for (volatile int d = 0; d < 200000; d++);

        /* Fault Injection Demo: Pressing the Blue Button (PC13) simulates an infinite loop! */
        if ((GPIOC_IDR & (1UL << 13)) == 0) {
            /* Firmware hangs without kicking IWDG: Watchdog resets MCU after 500ms */
            while (1) { /* Infinite Hang */ }
        }
    }

    return 0;
}

Module 4 Capstone Knowledge Check

Test your mastery of MISRA rules, table-driven state machines, and hardware fault handling.

1. Why does MISRA-C strictly prohibit dynamic memory allocation (malloc and free) in safety-critical firmware?

2. In HardFault_Handler, why is an assembly trampoline required before calling the C fault handler?

3. What is the key advantage of a 2D State Transition Matrix over a switch-case FSM?

4. Why does the Independent Watchdog (IWDG) use the internal 32kHz LSI oscillator instead of the main system clock (HSE/HSI)?

5. In the captured hardfault_stack_t structure, which register contains the memory address of the instruction that caused the CPU crash?

6. What does MISRA-C Rule 17.7 mandate regarding function return values?

7. How does firmware know after booting whether the reset was caused by power-up (POR) or a watchdog event (IWDG)?

8. What is 'Window Watchdog' (WWDG) behavior compared to regular watchdog (IWDG)?

9. Why is recursion prohibited in MISRA-C and safety-critical embedded systems?

10. In Doxygen, what tag documents the expected state or conditions that must be true BEFORE calling a function?
