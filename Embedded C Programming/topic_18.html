Topic 18

MISRA-C Concepts

MISRA-C provides guidance for safer, more analyzable C in critical systems. Key themes include avoiding undefined behavior, controlling implicit conversions, limiting hidden control flow, minimizing risky pointer use, and documenting deviations.

MISRA-C complements requirements, static analysis, peer review, unit testing, integration testing, and safety evidence. It is not a substitute for engineering judgment.
