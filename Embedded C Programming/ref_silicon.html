Engineering Reference 3

Microcontrollers (MCUs) vs. Microprocessors (MPUs)

A foundational architectural choice in any cyber-physical project is selecting the processing engine: a Microcontroller (MCU) or an application Microprocessor (MPU). This decision determines everything from interrupt latency and memory footprints to thermal dissipation, battery operating lifetime, and Bill of Materials (BOM) cost.

3.1 Core Pipeline & Memory Subsystem Contrast

Feature Dimension Microcontroller (MCU) Microprocessor (MPU)
Core Pipeline In-order, 2 to 6 stages (ARM Cortex-M0+/M4F/M7, RISC-V RV32) Out-of-order superscalar, 10 to 15+ stages (ARM Cortex-A53/A72, 64-bit)
Clock Frequency 16 MHz – 480 MHz (Rarely up to 1 GHz on crossover MCUs) 800 MHz – 2.8+ GHz
Memory Map Self-Contained Silicon: On-chip Flash (32 KB – 2 MB) + SRAM (8 KB – 512 KB). Code runs via eXecute In Place (XIP). External Subsystem: Requires external high-speed DDR4/LPDDR4 DRAM (1 GB – 16 GB) + eMMC flash storage.
Memory Management (MMU) No MMU. Flat physical memory space. Basic regional Memory Protection Unit (MPU) for task privilege isolation. Hardware MMU. Virtual memory paging, process isolation, translation lookaside buffers (TLBs).
Interrupt Latency Deterministic: 12 to 16 clock cycles (25 to 100 nanoseconds via hardware NVIC). Non-Deterministic: 5 to 50 microseconds (subject to OS kernel scheduler and TLB misses).
Power Consumption Active: 5 to 50 mA. Deep Sleep: 0.5 to 15 μA. 10-year battery life on coin cells. Active: 1.5W to 25W. Standby: 15 to 50 mA. Requires complex multi-rail PMICs and heat sinks.
Boot Latency < 5 milliseconds from power-on reset to executing C code in main(). 2 to 15 seconds (ROM bootloader → SPL → U-Boot → Linux kernel decompression).
Canonical Silicon STM32F4/G4/H7, Nordic nRF52/53, TI C2000, ESP32-S3, RP2040, NXP S32K NXP i.MX 8M Plus / 93, TI Sitara AM62x / AM64x, STM32MP157, Broadcom BCM2711

3.2 Asymmetric Heterogeneous Multiprocessing (AMP)

Modern complex embedded devices increasingly rely on AMP Hybrid System-on-Chips. For example, the NXP i.MX 8M Plus or TI Sitara AM6442 embeds:

  • Linux Application Domain (Cortex-A53 MPU): Runs high-level protocols (HTTP/REST, MQTT, Cloud TLS, GUI, Machine Learning vision models) where multi-threading and gigabytes of memory are required.
  • Hard Real-Time Core (Cortex-M7 / Cortex-R5F MCU): Runs a bare-metal loop or FreeRTOS with direct pin control over CAN-FD, ADC, and PWM timers, completely isolated from Linux crashes or scheduler pauses.
  • Inter-Processor Communication (IPC): The MPU and MCU exchange data deterministically across shared on-chip SRAM using hardware mailboxes and the RPMsg / OpenAMP standard.
