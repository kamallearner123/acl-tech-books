Topic 3

Compile, Runtime, Link, and Logic Errors

Classify the failure before fixing it. Compile errors stop translation, link errors stop image creation, runtime errors appear during execution, and logic errors produce incorrect behavior while appearing to run.

Debug sequence

  1. Reproduce the smallest failure.
  2. Read the first diagnostic.
  3. Check types, bounds, ownership, and state.
  4. Add a test or trace that distinguishes hypotheses.
  5. Fix the cause and preserve the regression.
