Module 3 Capstone Project

Reactive Systems, Interrupts & Ring Buffers

Real-time embedded firmware lives and dies by responsiveness. Hard deadlines cannot tolerate blocking loops (such as delay_ms()), and high-speed communication buses cannot drop bytes while the processor is busy. In this milestone, we bridge theory and practice by building two reactive systems: a POSIX signal-emulated interrupt simulator with lock-free SPSC circular buffers on Linux/WSL, and a hardware timer-scheduled, interrupt-driven UART Command Line Interface on physical STM32 hardware.

Concurrency Mechanism POSIX SIGALRM / Real-Time signals & C11 atomics Cortex-M NVIC hardware interrupts (TIM2 & USART2)

Part 1: Linux / WSL Project — POSIX Interrupt Simulator & Lock-Free Ring Buffer

How do embedded developers test interrupt handlers before hardware is available? On Linux/WSL, we emulate hardware interrupts using POSIX signals (timer_create / SIGALRM). Because POSIX signal handlers asynchronously interrupt the main thread just like an MCU ISR, they expose race conditions, reentrancy bugs, and atomic ordering failures.

Step 1: Lock-Free Ring Buffer Header (ring_buffer.h)

A single-producer, single-consumer (SPSC) ring buffer with power-of-two sizing, enabling bitwise index wrapping without expensive modulo (%) division: 

/**
 * @file ring_buffer.h
 * @brief Lock-Free SPSC Circular Buffer for Interrupt-to-Thread Communication
 */
#ifndef RING_BUFFER_H
#define RING_BUFFER_H

#include <stdint.h>
#include <stdbool.h>
#include <stddef.h>

#define RING_BUFFER_CAPACITY 64U /* Must be a power of two */
#define RING_BUFFER_MASK     (RING_BUFFER_CAPACITY - 1U)

typedef struct {
    uint8_t  buffer[RING_BUFFER_CAPACITY];
    volatile uint32_t head; /* Written by Producer (ISR), read by Consumer */
    volatile uint32_t tail; /* Written by Consumer (Task), read by Producer */
    volatile uint32_t drop_count;
} ring_buffer_t;

void     ring_buf_init(ring_buffer_t *rb);
bool     ring_buf_put(ring_buffer_t *rb, uint8_t byte);
bool     ring_buf_get(ring_buffer_t *rb, uint8_t *p_byte);
uint32_t ring_buf_count(const ring_buffer_t *rb);
bool     ring_buf_is_empty(const ring_buffer_t *rb);
bool     ring_buf_is_full(const ring_buffer_t *rb);

#endif /* RING_BUFFER_H */

Step 2: Lock-Free Implementation (ring_buffer.c)

Compiler barriers ensure the byte is committed to memory before the head index is incremented: 

/**
 * @file ring_buffer.c
 * @brief Lock-Free SPSC Implementation with Explicit Memory Barriers
 */
#include "ring_buffer.h"

void ring_buf_init(ring_buffer_t *rb) {
    if (rb != NULL) {
        rb->head = 0U;
        rb->tail = 0U;
        rb->drop_count = 0U;
    }
}

uint32_t ring_buf_count(const ring_buffer_t *rb) {
    return (rb->head - rb->tail);
}

bool ring_buf_is_full(const ring_buffer_t *rb) {
    return (ring_buf_count(rb) >= RING_BUFFER_CAPACITY);
}

bool ring_buf_is_empty(const ring_buffer_t *rb) {
    return (rb->head == rb->tail);
}

/* Producer Function: Called inside ISR */
bool ring_buf_put(ring_buffer_t *rb, uint8_t byte) {
    if (ring_buf_is_full(rb)) {
        rb->drop_count++;
        return false; /* Buffer overflow */
    }

    /* Store data at current head slot */
    rb->buffer[rb->head & RING_BUFFER_MASK] = byte;

    /* Memory Barrier: Ensure byte is written before head updates */
    __atomic_thread_fence(__ATOMIC_RELEASE);

    rb->head++;
    return true;
}

/* Consumer Function: Called inside Background Loop */
bool ring_buf_get(ring_buffer_t *rb, uint8_t *p_byte) {
    if (ring_buf_is_empty(rb)) {
        return false; /* Buffer empty */
    }

    *p_byte = rb->buffer[rb->tail & RING_BUFFER_MASK];

    /* Memory Barrier: Ensure byte is read before tail advances */
    __atomic_thread_fence(__ATOMIC_RELEASE);

    rb->tail++;
    return true;
}

Step 3: Signal-Emulated ISR Harness (host_sim.c)

A Linux program setting up a 10ms hardware interval timer via setitimer(), triggering an asynchronous signal handler that acts as our simulated ADC sensor ISR: 

/**
 * @file host_sim.c
 * @brief Host Signal-Emulated Interrupt Engine & Non-Blocking Scheduler
 */
#define _POSIX_C_SOURCE 200809L
#include <stdio.h>
#include <stdlib.h>
#include <signal.h>
#include <sys/time.h>
#include <unistd.h>
#include "ring_buffer.h"

static ring_buffer_t g_telemetry_rb;
static volatile sig_atomic_t g_irq_count = 0;
static volatile sig_atomic_t g_keep_running = 1;

/* Simulated Hardware Interrupt Service Routine (ISR) */
static void simulated_timer_isr(int sig) {
    (void)sig;
    g_irq_count++;

    /* Produce synthetic sensor byte (0x30 to 0x39) */
    uint8_t synthetic_byte = (uint8_t)('0' + (g_irq_count % 10));
    ring_buf_put(&g_telemetry_rb, synthetic_byte);
}

int main(void) {
    printf("=== POSIX SIGNAL-EMULATED INTERRUPT ENGINE ===\n");
    ring_buf_init(&g_telemetry_rb);

    /* 1. Register Simulated ISR via SIGALRM */
    struct sigaction sa;
    sa.sa_handler = simulated_timer_isr;
    sa.sa_flags = SA_RESTART;
    sigemptyset(&sa.sa_mask);
    sigaction(SIGALRM, &sa, NULL);

    /* 2. Configure 10ms Interval Timer */
    struct itimerval timer;
    timer.it_interval.tv_sec = 0;
    timer.it_interval.tv_usec = 10000; /* 10 ms periodic tick */
    timer.it_value.tv_sec = 0;
    timer.it_value.tv_usec = 10000;
    setitimer(ITIMER_REAL, &timer, NULL);

    printf("Simulated hardware interrupts running at 100 Hz. Processing in non-blocking superloop...\n");

    uint32_t processed_bytes = 0;
    while (processed_bytes < 50) {
        uint8_t rx_data;
        /* Non-blocking drain: Never wait or block */
        if (ring_buf_get(&g_telemetry_rb, &rx_data)) {
            printf("[Main Loop Task] Received Sensor Byte: '%c' (Total Processed: %u)\n", 
                   rx_data, ++processed_bytes);
        }

        /* Simulate non-blocking concurrent work */
        usleep(5000); /* 5 ms background cycle */
    }

    /* Disable timer */
    timer.it_value.tv_usec = 0;
    timer.it_interval.tv_usec = 0;
    setitimer(ITIMER_REAL, &timer, NULL);

    printf("Execution Finished: %d IRQs fired, %u bytes processed, %u dropped.\n",
           g_irq_count, processed_bytes, g_telemetry_rb.drop_count);

    return 0;
}

Part 2: Physical STM32 Board Project — Hardware Timer & Interrupt-Driven UART CLI

On real hardware, blocking UART reads freeze the MCU and miss external events. Here, we implement a full Interrupt-Driven USART2 Driver with Lock-Free Circular Buffer paired with a 1kHz Hardware Timer (TIM2) Periodic Scheduler on an STM32F4 Nucleo board.

System Architecture & NVIC Configuration

[USART2 RX Pin (PA3)] --> (RXNE Interrupt) --> [USART2_IRQHandler] --> ring_buf_put() | [Main Superloop] <-------------------------------------------------------+ | +--> ring_buf_get() --> Command Line Parser ("led on", "status") | [TIM2 1kHz Tick] ----> Non-blocking software timers for 2Hz LED heartbeat

Bare-Metal Implementation (stm32_cli.c)

/**
 * @file stm32_cli.c
 * @brief Interrupt-Driven USART2 & Hardware Timer Scheduler for STM32F401
 */
#include <stdint.h>
#include <stdbool.h>

/* Register Offsets */
#define RCC_AHB1ENR   (*(volatile uint32_t *)(0x40023830UL))
#define RCC_APB1ENR   (*(volatile uint32_t *)(0x40023840UL))

#define GPIOA_MODER   (*(volatile uint32_t *)(0x40020000UL))
#define GPIOA_AFRL    (*(volatile uint32_t *)(0x40020020UL))
#define GPIOA_BSRR    (*(volatile uint32_t *)(0x40020018UL))

#define USART2_SR     (*(volatile uint32_t *)(0x40004400UL))
#define USART2_DR     (*(volatile uint32_t *)(0x40004404UL))
#define USART2_BRR    (*(volatile uint32_t *)(0x40004408UL))
#define USART2_CR1    (*(volatile uint32_t *)(0x4000440CUL))

#define NVIC_ISER1    (*(volatile uint32_t *)(0xE000E104UL)) /* IRQ 32-63 */
#define NVIC_ISER0    (*(volatile uint32_t *)(0xE000E100UL)) /* IRQ 0-31 */

#define TIM2_CR1      (*(volatile uint32_t *)(0x40000000UL))
#define TIM2_DIER     (*(volatile uint32_t *)(0x4000000CUL))
#define TIM2_SR       (*(volatile uint32_t *)(0x40000010UL))
#define TIM2_PSC      (*(volatile uint32_t *)(0x40000028UL))
#define TIM2_ARR      (*(volatile uint32_t *)(0x4000002CUL))

/* Circular Buffer for UART RX */
#define UART_BUF_SIZE 64U
typedef struct {
    uint8_t  buf[UART_BUF_SIZE];
    volatile uint32_t head;
    volatile uint32_t tail;
} uart_rx_buffer_t;

static uart_rx_buffer_t g_uart_rx = { .head = 0, .tail = 0 };
static volatile uint32_t g_system_ticks = 0; /* Incremented every 1ms by TIM2 */

/* USART2 Interrupt Service Routine */
void USART2_IRQHandler(void) {
    /* Check if Read Data Register Not Empty (RXNE) */
    if (USART2_SR & (1UL << 5)) {
        uint8_t rx_char = (uint8_t)(USART2_DR & 0xFFU);
        uint32_t next_head = (g_uart_rx.head + 1U) % UART_BUF_SIZE;
        if (next_head != g_uart_rx.tail) {
            g_uart_rx.buf[g_uart_rx.head] = rx_char;
            g_uart_rx.head = next_head;
        }
    }
}

/* TIM2 1kHz Tick Interrupt Service Routine */
void TIM2_IRQHandler(void) {
    if (TIM2_SR & (1UL << 0)) { /* Update Interrupt Flag */
        TIM2_SR &= ~(1UL << 0);  /* Clear Flag */
        g_system_ticks++;
    }
}

static void uart_send_char(char c) {
    while (!(USART2_SR & (1UL << 7))) { /* Wait for TXE */ }
    USART2_DR = (uint32_t)c;
}

static void uart_send_str(const char *str) {
    while (*str) {
        uart_send_char(*str++);
    }
}

static void periph_init(void) {
    /* 1. Clocks: GPIOA, USART2, TIM2 */
    RCC_AHB1ENR |= (1UL << 0);  /* GPIOA */
    RCC_APB1ENR |= (1UL << 17); /* USART2 */
    RCC_APB1ENR |= (1UL << 0);  /* TIM2 */

    /* 2. PA5 (LED) Output */
    GPIOA_MODER &= ~(3UL << 10);
    GPIOA_MODER |=  (1UL << 10);

    /* 3. PA2 (TX) and PA3 (RX) Alternate Function AF7 */
    GPIOA_MODER &= ~((3UL << 4) | (3UL << 6));
    GPIOA_MODER |=  ((2UL << 4) | (2UL << 6));
    GPIOA_AFRL  |=  ((7UL << 8) | (7UL << 12));

    /* 4. USART2: 115200 Baud @ 16MHz APB1 Clock */
    USART2_BRR = 0x008B; /* 16MHz / (16 * 115200) = 8.6875 -> 0x8B */
    USART2_CR1 = (1UL << 13) | (1UL << 3) | (1UL << 2) | (1UL << 5); /* UE, TE, RE, RXNEIE */

    /* 5. TIM2: 1000 Hz Tick (1ms) */
    TIM2_PSC = 16 - 1;    /* Prescale to 1MHz */
    TIM2_ARR = 1000 - 1;  /* 1MHz / 1000 = 1kHz */
    TIM2_DIER |= (1UL << 0); /* Update Interrupt Enable */
    TIM2_CR1  |= (1UL << 0); /* Counter Enable */

    /* 6. Enable Interrupts in NVIC */
    NVIC_ISER1 |= (1UL << (38 - 32)); /* USART2 is IRQ 38 */
    NVIC_ISER0 |= (1UL << 28);        /* TIM2 is IRQ 28 */
}

/* Non-blocking CLI parser executed in main superloop */
static void process_cli(void) {
    static char cmd_line[32];
    static uint8_t idx = 0;

    while (g_uart_rx.head != g_uart_rx.tail) {
        char c = (char)g_uart_rx.buf[g_uart_rx.tail];
        g_uart_rx.tail = (g_uart_rx.tail + 1U) % UART_BUF_SIZE;
        uart_send_char(c); /* Local Echo */

        if (c == '\r' || c == '\n') {
            cmd_line[idx] = '\0';
            uart_send_str("\r\n");

            if (idx > 0) {
                if (cmd_line[0] == '1') {
                    GPIOA_BSRR = (1UL << 5);
                    uart_send_str("[OK] LED ON\r\n> ");
                } else if (cmd_line[0] == '0') {
                    GPIOA_BSRR = (1UL << (5 + 16));
                    uart_send_str("[OK] LED OFF\r\n> ");
                } else {
                    uart_send_str("[ERR] Unknown: Press '1' for ON, '0' for OFF\r\n> ");
                }
            }
            idx = 0;
        } else if (idx < (sizeof(cmd_line) - 1U)) {
            cmd_line[idx++] = c;
        }
    }
}

int main(void) {
    periph_init();
    uart_send_str("\r\n=== STM32 REACTIVE UART CLI READY ===\r\n> ");

    uint32_t last_heartbeat = 0;

    while (1) {
        /* Task 1: Non-Blocking CLI Processor */
        process_cli();

        /* Task 2: Non-Blocking Heartbeat LED Toggle every 1000 ms */
        if ((g_system_ticks - last_heartbeat) >= 1000U) {
            last_heartbeat = g_system_ticks;
            /* Heartbeat pulse */
            GPIOA_BSRR = (1UL << 5);
            /* Short pulse turn-off managed without delay */
        }
    }

    return 0;
}

Module 3 Capstone Knowledge Check

Test your understanding of reactive architecture, interrupt safety, and lock-free data structures.

1. In an SPSC circular buffer with capacity equal to a power of two ($2^N$), why is (head & (CAPACITY - 1)) preferred over (head % CAPACITY)?

2. Why is a memory barrier (__atomic_thread_fence) required before incrementing rb->head in ring_buf_put()?

3. What is the fatal flaw of calling printf() inside an Interrupt Service Routine (ISR)?

4. Why must g_system_ticks be declared with the volatile qualifier?

5. In non-blocking scheduling, how should elapsed time be checked to prevent bugs when g_system_ticks overflows (wraps around to 0)?

6. What is the consequence if the USART2 RXNE interrupt flag is NOT cleared or read inside USART2_IRQHandler()?

7. Why is a Single-Producer Single-Consumer (SPSC) ring buffer inherently thread-safe without mutex locks?

8. What occurs when a UART peripheral receives a new byte before the previous byte has been read from the Data Register?

9. What is the fundamental difference between cooperative non-blocking scheduling and preemptive RTOS scheduling?

10. What is 'Interrupt Latency' in embedded systems?

Hands-on Engineering Challenges

Challenge 1 (Host)

Stress-Test Multi-Threaded SPSC Benchmark

Write a host program using POSIX pthread with one thread acting as a 100kHz producer and another as a consumer. Push 10,000,000 uint32 integers through the ring buffer and verify zero data corruption or dropped items.

Challenge 2 (Host)

Priority Callback Event Queue

Implement an event scheduler in C where events have priority levels (HIGH, MEDIUM, LOW). When multiple events are queued, the dispatcher always fires high-priority callbacks first.

Challenge 3 (STM32)

DMA-Assisted Circular UART Reception

Upgrade the STM32 UART receiver to use Direct Memory Access (DMA1 Stream 5) in circular mode. This moves characters from the UART data register directly into memory with zero CPU interrupt overhead.

Challenge 4 (STM32)

Non-Blocking Rotary Encoder Quadrature Decoder

Configure STM32 TIM3 in Encoder Mode (quadrature interface on PA6/PA7). In the non-blocking superloop, sample encoder ticks and adjust an LED PWM brightness without any busy-wait polling.

Challenge 5 (Host + Hardware)

Interactive Telemetry Dashboard CLI

Extend the CLI parser to support commands: uptime (returns millis), temp (returns simulated sensor data), and reboot (triggers software reset via NVIC AIRCR register).
