Topic 4

Assertions, Logging, and Debugging Methodology

Assertions turn developer assumptions into executable checks. Logging records state, error codes, and transitions. A disciplined debugger reproduces, minimizes, hypothesizes, instruments, fixes, and adds a regression test.

#include <assert.h>
assert(buffer != NULL);
assert(length <= capacity);

Use bounded logging outside critical ISRs and use GDB watchpoints, breakpoints, call stacks, and register inspection when debugging a target.
