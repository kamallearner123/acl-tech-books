Topic 6

Preprocessor → Compiler → Assembler → Linker → Executable

  1. Preprocessor expands includes, macros, and conditional compilation.
  2. Compiler checks C and produces assembly or object representation.
  3. Assembler creates relocatable object files.
  4. Linker resolves symbols and places sections according to memory rules.
  5. The executable or firmware image is loaded or programmed onto the target.

Inspect intermediate artifacts to understand where a failure was introduced.
