Topic 1

C Programming History & Tools

C evolved from systems programming work at Bell Labs and became a foundation for operating systems, compilers, and embedded firmware because it offers direct memory access with a small runtime model.

Tools

Use an editor, GCC or a cross-compiler, a debugger, Make/CMake, static analysis, tests, and Git. The toolchain turns readable source into a target-specific executable and provides evidence that the result is correct.

gcc -std=c11 -Wall -Wextra main.c -o main
./main

Practice

Build a small C program on Linux, enable warnings, inspect the binary size, and commit the working version.
