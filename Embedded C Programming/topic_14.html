Topic 14

Non-Blocking Firmware Design

Blocking delays hide the CPU from other work. Non-blocking code stores a deadline or state, returns control to the loop, and resumes when the required event arrives.

void application_step(uint32_t now)
{
    if ((int32_t)(now - next_deadline) >= 0) {
        next_deadline = now + PERIOD_TICKS;
        request_sample();
    }
    service_communication();
}

Bound each step, define tick wraparound behavior, and use events or queues for slow work.
