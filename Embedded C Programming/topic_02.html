C Programming Best Practices

Good embedded C is explicit about types, ownership, bounds, units, lifetime, side effects, and failure behavior.

  • Use fixed-width types and named constants.
  • Keep functions small and single-purpose.
  • Pass buffers with lengths and document ownership.
  • Compile with warnings and review every diagnostic.
  • Prefer deterministic storage and bounded loops.

Practice

Refactor a function containing magic numbers, hidden globals, and unchecked input into a documented, testable API.
