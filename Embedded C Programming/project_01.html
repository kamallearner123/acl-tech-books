Module 1 Capstone Project

C Foundations, Safety & Hardware Diagnostics

Having mastered the foundational pillars of Embedded C—fixed-width types, memory boundaries, common compiler traps, assertions, defensive logging, and unit testing—it is time to consolidate this knowledge. This milestone features two complete, standalone engineering projects: one optimized for host simulation on Linux/WSL using GCC, sanitizers, and Unity; and one deployed bare-metal on an STM32 microcontroller using direct register access and hardware-level panic diagnostics.

Part 1: Linux / WSL Project — Safe Telemetry Packet Decoder

In distributed embedded systems (automotive CAN, avionics ARINC, IoT MQTT), sensor nodes transmit serialized binary frames over raw serial channels. A fundamental embedded programming skill is decoding packed frames into typed C structs safely—without buffer overruns, endianness bugs, or undefined behavior.

System Architecture & Frame Specification

The host simulator decodes binary packets structured according to a strict communication protocol:

[0xAA] [0x55] | [Msg_ID: 1B] | [Payload_Len: 1B] | [Data: N Bytes (Max 32)] | [CRC16: 2B (Little Endian)]
  • Sync Bytes: 0xAA, 0x55 (Must match or frame is rejected immediately).
  • Message ID: 0x01 (Battery Status), 0x02 (IMU Attitude), 0x03 (Motor Faults).
  • Payload Length: 1 to 32 bytes. Any length exceeding 32 triggers a length violation assert.
  • Data Integrity: CCITT-CRC16 checksum across Header + Payload bytes.

Step 1: Header Definition (telemetry.h)

Strict use of <stdint.h>, <stdbool.h>, defensive error codes, and macro assertions: 

/**
 * @file telemetry.h
 * @brief Defensive Telemetry Frame Decoder Interface
 */
#ifndef TELEMETRY_H
#define TELEMETRY_H

#include <stdint.h>
#include <stdbool.h>
#include <stddef.h>

#define TELEMETRY_SYNC_BYTE1      0xAAU
#define TELEMETRY_SYNC_BYTE2      0x55U
#define TELEMETRY_MAX_PAYLOAD_LEN 32U
#define TELEMETRY_MIN_FRAME_LEN   6U  /* 2 sync + 1 id + 1 len + 2 crc */

typedef enum {
    TELEM_OK = 0,
    TELEM_ERR_NULL_PTR,
    TELEM_ERR_FRAME_TOO_SHORT,
    TELEM_ERR_BAD_SYNC,
    TELEM_ERR_INVALID_LENGTH,
    TELEM_ERR_CRC_MISMATCH,
    TELEM_ERR_UNKNOWN_MSG_ID
} telem_status_t;

typedef struct {
    uint8_t  msg_id;
    uint8_t  payload_len;
    uint8_t  payload[TELEMETRY_MAX_PAYLOAD_LEN];
    uint16_t crc16;
} telem_frame_t;

/* Defensive Assertion with Return Code */
#define EMB_ASSERT_RETURN(cond, err_code) \
    do { \
        if (!(cond)) { \
            return (err_code); \
        } \
    } while (0)

/* API Prototypes */
uint16_t telem_compute_crc16(const uint8_t *data, size_t length);
telem_status_t telem_decode_frame(const uint8_t *raw_buf, size_t buf_len, telem_frame_t *out_frame);

#endif /* TELEMETRY_H */

Step 2: Robust Implementation (telemetry.c)

This decoder checks all boundaries before pointer dereferencing, calculates CRC16 dynamically, and unpacks multi-byte integers using explicit byte shifts (endian-neutral): 

/**
 * @file telemetry.c
 * @brief Defensive Frame Decoder Implementation
 */
#include "telemetry.h"

uint16_t telem_compute_crc16(const uint8_t *data, size_t length) {
    if (data == NULL || length == 0U) {
        return 0U;
    }
    uint16_t crc = 0xFFFFU;
    for (size_t i = 0; i < length; i++) {
        crc ^= (uint16_t)data[i];
        for (uint8_t bit = 0; bit < 8U; bit++) {
            if ((crc & 0x0001U) != 0U) {
                crc = (crc >> 1U) ^ 0x8408U; /* Reversed CCITT polynomial */
            } else {
                crc = crc >> 1U;
            }
        }
    }
    return crc;
}

telem_status_t telem_decode_frame(const uint8_t *raw_buf, size_t buf_len, telem_frame_t *out_frame) {
    EMB_ASSERT_RETURN(raw_buf != NULL, TELEM_ERR_NULL_PTR);
    EMB_ASSERT_RETURN(out_frame != NULL, TELEM_ERR_NULL_PTR);
    EMB_ASSERT_RETURN(buf_len >= TELEMETRY_MIN_FRAME_LEN, TELEM_ERR_FRAME_TOO_SHORT);

    /* 1. Verify Synchronization Header */
    if ((raw_buf[0] != TELEMETRY_SYNC_BYTE1) || (raw_buf[1] != TELEMETRY_SYNC_BYTE2)) {
        return TELEM_ERR_BAD_SYNC;
    }

    uint8_t msg_id = raw_buf[2];
    uint8_t payload_len = raw_buf[3];

    /* 2. Validate Payload Length */
    if (payload_len > TELEMETRY_MAX_PAYLOAD_LEN) {
        return TELEM_ERR_INVALID_LENGTH;
    }

    /* 3. Check Full Frame Length Boundary */
    size_t expected_total_len = 4U + (size_t)payload_len + 2U;
    if (buf_len < expected_total_len) {
        return TELEM_ERR_FRAME_TOO_SHORT;
    }

    /* 4. Extract Checksum (Little-Endian) */
    size_t crc_idx = 4U + (size_t)payload_len;
    uint16_t expected_crc = (uint16_t)raw_buf[crc_idx] | ((uint16_t)raw_buf[crc_idx + 1U] << 8U);

    /* 5. Compute CRC over Header & Payload */
    uint16_t calc_crc = telem_compute_crc16(&raw_buf[2], 2U + (size_t)payload_len);
    if (calc_crc != expected_crc) {
        return TELEM_ERR_CRC_MISMATCH;
    }

    /* 6. Populate Output Frame */
    out_frame->msg_id = msg_id;
    out_frame->payload_len = payload_len;
    out_frame->crc16 = expected_crc;
    for (uint8_t i = 0; i < payload_len; i++) {
        out_frame->payload[i] = raw_buf[4U + i];
    }

    return TELEM_OK;
}

Step 3: Automated Unit Test Suite (test_telemetry.c)

Writing tests for edge cases: null pointers, corrupted sync headers, truncated payloads, and CRC injection errors. 

/**
 * @file test_telemetry.c
 * @brief Host-Based Regression Suite using Unity
 */
#include <stdio.h>
#include <string.h>
#include <assert.h>
#include "telemetry.h"

/* Lightweight Host Test Harness */
static int tests_run = 0;
static int tests_passed = 0;

#define TEST_ASSERT(expr, msg) do { \
    tests_run++; \
    if (expr) { \
        tests_passed++; \
        printf("  [PASS] %s\n", msg); \
    } else { \
        printf("  [FAIL] %s (Line %d)\n", msg, __LINE__); \
    } \
} while(0)

void test_null_pointers(void) {
    telem_frame_t frame;
    uint8_t buf[16] = {0xAA, 0x55, 0x01, 0x01, 0x42, 0x00, 0x00};
    
    TEST_ASSERT(telem_decode_frame(NULL, sizeof(buf), &frame) == TELEM_ERR_NULL_PTR, "Rejects NULL input buffer");
    TEST_ASSERT(telem_decode_frame(buf, sizeof(buf), NULL) == TELEM_ERR_NULL_PTR, "Rejects NULL output frame");
}

void test_valid_packet(void) {
    /* Packet: Sync(0xAA, 0x55), ID(0x01), Len(0x02), Data(0x10, 0x20) */
    uint8_t buf[8] = {0xAA, 0x55, 0x01, 0x02, 0x10, 0x20, 0x00, 0x00};
    uint16_t crc = telem_compute_crc16(&buf[2], 4);
    buf[6] = (uint8_t)(crc & 0xFFU);
    buf[7] = (uint8_t)((crc >> 8U) & 0xFFU);

    telem_frame_t frame;
    telem_status_t status = telem_decode_frame(buf, sizeof(buf), &frame);

    TEST_ASSERT(status == TELEM_OK, "Decodes valid frame successfully");
    TEST_ASSERT(frame.msg_id == 0x01, "Correct message ID extracted");
    TEST_ASSERT(frame.payload_len == 2, "Correct payload length extracted");
    TEST_ASSERT(frame.payload[0] == 0x10 && frame.payload[1] == 0x20, "Payload data intact");
}

void test_bad_crc(void) {
    uint8_t buf[8] = {0xAA, 0x55, 0x01, 0x02, 0x10, 0x20, 0xDE, 0xAD};
    telem_frame_t frame;
    telem_status_t status = telem_decode_frame(buf, sizeof(buf), &frame);

    TEST_ASSERT(status == TELEM_ERR_CRC_MISMATCH, "Detects corrupted CRC checksum");
}

void test_oversized_payload_rejection(void) {
    uint8_t buf[64] = {0xAA, 0x55, 0x01, 35}; /* Len 35 > Max 32 */
    telem_frame_t frame;
    telem_status_t status = telem_decode_frame(buf, sizeof(buf), &frame);

    TEST_ASSERT(status == TELEM_ERR_INVALID_LENGTH, "Rejects packet with length > 32");
}

int main(void) {
    printf("=== RUNNING MODULE 1 TELEMETRY UNIT TESTS ===\n");
    test_null_pointers();
    test_valid_packet();
    test_bad_crc();
    test_oversized_payload_rejection();
    printf("Summary: %d / %d tests passed.\n", tests_passed, tests_run);
    return (tests_passed == tests_run) ? 0 : 1;
}

Step 4: Building with AddressSanitizer & Valgrind

Compile in your Linux terminal or WSL bash session with maximum diagnostic flags: 

# Compile with C11, all warnings as errors, and AddressSanitizer
gcc -std=c11 -Wall -Wextra -Werror -pedantic -fsanitize=address,undefined -g telemetry.c test_telemetry.c -o test_runner

# Execute the test suite
./test_runner

# Verify with Valgrind for zero memory leaks
valgrind --leak-check=full --show-leak-kinds=all ./test_runner

Part 2: Physical STM32 Board Project — Bare-Metal Diagnostics & Assert Engine

On an embedded target, when an assert fails, there is no terminal to print to and no OS to terminate the process. In safety-critical systems, an assert failure must trigger a controlled fail-safe halt: disabling motor drives, recording the source file and line to non-volatile RAM, and visually pulsing an error code on a diagnostic LED.

Hardware Mapping: STM32F401RE / STM32F411RE Nucleo

  • Target MCU: STM32F401RE (ARM Cortex-M4 @ 84MHz, 512KB Flash, 96KB SRAM).
  • Green User LED (LD2): Connected to GPIOA Pin 5 (Active High).
  • User Blue Pushbutton (B1): Connected to GPIOC Pin 13 (Active Low, Pull-Up).
  • Direct Memory Bus: AHB1 Peripheral Bus controls RCC (Base: 0x40023800) and GPIOA (Base: 0x40020000).

Bare-Metal Implementation (main.c)

The following pure C program requires zero vendor HAL or CubeMX libraries. It accesses hardware registers through strict volatile uint32_t * pointers and implements a hardware diagnostic assert handler: 

/**
 * @file main.c
 * @brief STM32F4 Bare-Metal Hardware Assert & GPIO Diagnostics
 * Target: STM32F401RE / STM32F411RE Nucleo-64
 */
#include <stdint.h>
#include <stdbool.h>

/* Base Addresses for STM32F4 Peripherals */
#define PERIPH_BASE       (0x40000000UL)
#define AHB1PERIPH_BASE   (PERIPH_BASE + 0x00020000UL)

/* RCC Register Map */
#define RCC_BASE          (AHB1PERIPH_BASE + 0x3800UL)
#define RCC_AHB1ENR       (*(volatile uint32_t *)(RCC_BASE + 0x30UL))
#define RCC_AHB1ENR_GPIOAEN (1UL << 0)
#define RCC_AHB1ENR_GPIOCEN (1UL << 2)

/* GPIOA (User LED on PA5) */
#define GPIOA_BASE        (AHB1PERIPH_BASE + 0x0000UL)
#define GPIOA_MODER       (*(volatile uint32_t *)(GPIOA_BASE + 0x00UL))
#define GPIOA_ODR         (*(volatile uint32_t *)(GPIOA_BASE + 0x14UL))
#define GPIOA_BSRR        (*(volatile uint32_t *)(GPIOA_BASE + 0x18UL))

/* GPIOC (User Button on PC13) */
#define GPIOC_BASE        (AHB1PERIPH_BASE + 0x0800UL)
#define GPIOC_MODER       (*(volatile uint32_t *)(GPIOC_BASE + 0x00UL))
#define GPIOC_IDR         (*(volatile uint32_t *)(GPIOC_BASE + 0x10UL))

#define LED_PIN           5UL
#define BUTTON_PIN        13UL

/* Diagnostic Error Record Stored in Uninitialized RAM */
typedef struct {
    const char *file;
    uint32_t    line;
    uint32_t    fault_code;
} diagnostic_record_t;

/* Global diagnostic block preserved across soft resets */
__attribute__((section(".noinit"))) diagnostic_record_t g_last_fault;

/* Software Delay Routine */
static void delay_cycles(volatile uint32_t count) {
    while (count > 0) {
        count--;
    }
}

/* Hardware Panic: Morse / Blink Error Code and Halt */
void hardware_assert_failed(const char *file, uint32_t line, uint32_t code) {
    /* 1. Disable all interrupts for atomic halt */
    __asm volatile ("cpsid i" : : : "memory");

    /* 2. Store fault telemetry for SWD/GDB debugger */
    g_last_fault.file = file;
    g_last_fault.line = line;
    g_last_fault.fault_code = code;

    /* 3. Infinite SOS / Blink Alarm on User LED */
    while (1) {
        /* Blink N times corresponding to error code */
        for (uint32_t i = 0; i < code; i++) {
            GPIOA_BSRR = (1UL << LED_PIN);          /* LED ON */
            delay_cycles(200000);
            GPIOA_BSRR = (1UL << (LED_PIN + 16UL)); /* LED OFF */
            delay_cycles(200000);
        }
        /* Long pause between code bursts */
        delay_cycles(1200000);
    }
}

/* Custom Embedded Assert Macro */
#define EMB_ASSERT(expr, err_code) \
    do { \
        if (!(expr)) { \
            hardware_assert_failed(__FILE__, __LINE__, (err_code)); \
        } \
    } while(0)

/* Initialize Clocks and GPIO Pins */
static void gpio_init(void) {
    /* Enable GPIOA and GPIOC Peripheral Clocks */
    RCC_AHB1ENR |= (RCC_AHB1ENR_GPIOAEN | RCC_AHB1ENR_GPIOCEN);

    /* Configure PA5 as General Purpose Output (MODER = 01) */
    GPIOA_MODER &= ~(3UL << (LED_PIN * 2));
    GPIOA_MODER |=  (1UL << (LED_PIN * 2));

    /* Configure PC13 as Input (MODER = 00) */
    GPIOC_MODER &= ~(3UL << (BUTTON_PIN * 2));
}

int main(void) {
    gpio_init();

    uint32_t loop_counter = 0;

    while (1) {
        /* Read Blue Button on PC13 (Active LOW on Nucleo) */
        bool button_pressed = ((GPIOC_IDR & (1UL << BUTTON_PIN)) == 0);

        /* Intentional Fault Injection: Pressing the button triggers Error Code 3 */
        EMB_ASSERT(!button_pressed, 3);

        /* Normal Heartbeat Blink */
        GPIOA_BSRR = (1UL << LED_PIN);
        delay_cycles(400000);
        GPIOA_BSRR = (1UL << (LED_PIN + 16UL));
        delay_cycles(400000);

        loop_counter++;
        /* Mathematical Invariant: Loop counter must never wrap negatively */
        EMB_ASSERT(loop_counter > 0, 1);
    }

    return 0;
}

Compiling, Flashing, and Debugging on Hardware

From your Linux/WSL terminal connected to the STM32 Nucleo via USB: 

# 1. Compile with arm-none-eabi-gcc targeting Cortex-M4
arm-none-eabi-gcc -mcpu=cortex-m4 -mthumb -mfloat-abi=hard -mfpu=fpv4-sp-d16 \
    -O2 -Wall -Wextra -Werror -g3 -c main.c -o main.o

# 2. Link with minimal startup and linker script (details in Module 2)
arm-none-eabi-gcc -mcpu=cortex-m4 -mthumb -T STM32F401RETx_FLASH.ld \
    main.o startup_stm32f401xe.o -o firmware.elf

# 3. Convert ELF to raw binary
arm-none-eabi-objcopy -O binary firmware.elf firmware.bin

# 4. Flash to STM32 board using ST-LINK CLI or st-flash
st-flash write firmware.bin 0x08000000

# 5. Connect GDB to inspect g_last_fault if an assert fires
arm-none-eabi-gdb firmware.elf
(gdb) target extended-remote :3333
(gdb) print g_last_fault

Module 1 Capstone Knowledge Check

Test your understanding of the concepts applied across both Linux and STM32 projects.

1. In telemetry.c, why is the 16-bit CRC reconstructed using explicit byte shifts (buf[0] | (buf[1] << 8)) rather than casting the buffer pointer directly to (uint16_t *)?

2. When hardware_assert_failed() is called on STM32, what is the critical purpose of __asm volatile ("cpsid i")?

3. What does __attribute__((section(".noinit"))) ensure for the g_last_fault variable?

4. Why is GPIOA_BSRR preferred over GPIOA_ODR for turning the LED on and off in embedded firmware?

5. Which GCC compiler flag flags out-of-bounds array reads and stack buffer overflows at runtime in our Linux project?

6. In EMB_ASSERT_RETURN(cond, err_code), why is the macro wrapped in do { ... } while(0)?

7. What is the danger of using int instead of uint32_t when creating bitmask shifts such as (1 << 31)?

8. When reading the user button state on PC13 with (GPIOC_IDR & (1UL << 13)) == 0, why does 0 indicate 'pressed'?

9. What happens if volatile is omitted from the hardware register pointers (e.g. #define GPIOA_ODR (*(uint32_t *)...))?

10. Why is Valgrind or ASan essential when verifying embedded C code on a Linux host?

Challenge 1 (Host)

Corrupted Packet Stream Fuzz Testing

Challenge 2 (Host)

Dynamic Payload Type Dispatcher

Extend telemetry.c with a message handler table: for msg_id = 0x01, unpack battery millivolts and temperature into a battery_telemetry_t struct; for msg_id = 0x02, unpack 3-axis accelerometer readings.

Challenge 3 (STM32)

Morse Code SOS Panic Generator

Modify hardware_assert_failed() on STM32 so that instead of simple N-blinks, it flashes international Morse code for "SOS" (... --- ...: 3 short, 3 long, 3 short) with precise timing intervals.

Challenge 4 (STM32)

Button Debounce Filter without Delay

Implement a software integrator debounce algorithm for PC13 that samples the pin every 5ms in the main loop and requires 4 consecutive identical readings before recognizing a valid button press.

Host ↔ Target Telemetry Loopback
