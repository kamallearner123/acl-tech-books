Topic 12

Polling vs Interrupts

Polling repeatedly checks conditions and is simple to trace. Interrupts let hardware signal asynchronous activity and can reduce response latency.

while (1) {
    check_button();
    check_sensor();
    check_timer();
}

void UART_IRQHandler(void)
{
    queue_push_from_isr(UART_DATA);
}

Keep interrupt handlers short: acknowledge, capture, signal, and return. Defer parsing and slow work.
