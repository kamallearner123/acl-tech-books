Topic 8

objdump, size, nm, and GDB

  • size reports text, data, and BSS footprint.
  • nm lists symbols and addresses.
  • objdump shows sections and disassembly.
  • gdb provides breakpoints, watchpoints, stacks, registers, and stepping.
size firmware.elf
nm firmware.elf
objdump -h -d firmware.elf
gdb ./host_test
