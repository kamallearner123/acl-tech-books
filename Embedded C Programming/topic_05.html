Topic 5

Unit Testing Concepts

A unit test exercises one function or module through a stable interface. Replace hardware with fakes or stubs so logic runs on the host compiler.

#include <assert.h>
static unsigned clamp(unsigned value){ return value > 100u ? 100u : value; }
int main(void){ assert(clamp(0u)==0u); assert(clamp(100u)==100u); assert(clamp(101u)==100u); }

Test nominal values, boundaries, invalid inputs, error paths, repeated calls, and reset behavior.
