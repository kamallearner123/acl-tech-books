Topic 7

GCC and Cross-Compilers

Host GCC builds code for the development computer. A cross-compiler such as arm-none-eabi-gcc emits code for a target MCU and uses target CPU, ABI, runtime, and linker settings.

gcc -std=c11 -Wall -Wextra main.c -o main
arm-none-eabi-gcc -mcpu=cortex-m4 -mthumb -c main.c -o main.o
