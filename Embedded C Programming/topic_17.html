Topic 17

Documentation Practices

Document why a constraint exists and state the API contract: units, valid ranges, ownership, lifetime, blocking behavior, execution context, side effects, errors, and reset behavior.

A README should show how to build, test, inspect warnings, reproduce a failure, and configure the target. Keep diagrams and state tables close to the code they explain.
