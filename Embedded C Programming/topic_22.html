Topic 22

Interfaces, APIs, and Abstraction

An API expresses what a component does without exposing how it does it. Good interfaces define inputs, outputs, ownership, timing, context, side effects, and errors.

int sensor_read(struct Sensor *sensor,
                uint16_t *value,
                uint32_t timeout_ms);

The caller should not need to know whether the implementation uses I2C, SPI, a fake, or a recorded test fixture.
