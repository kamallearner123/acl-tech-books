Competencies

Course Learning Outcomes

Upon completing this comprehensive curriculum and its associated milestone projects, engineers will possess the theoretical mastery and hands-on skill set required to architect, write, debug, and certify commercial-grade embedded C firmware:

⚙

1. Low-Level Control & Type Discipline

  • Eliminate undefined behavior (UB), signed integer overflow, and sequence point violations using strict <stdint.h> types.
  • Directly manipulate hardware memory-mapped registers using volatile pointers and atomic bitmasking techniques.
  • Decode multi-byte telemetry packets across network/serial streams while maintaining absolute endianness neutrality.
🔨

2. Toolchain Mastery & Linker Scripts

  • Build and cross-compile firmware from raw command-line with arm-none-eabi-gcc, Make, and CMake without IDE lock-in.
  • Handcraft custom GNU Linker Scripts (.ld) defining Flash/SRAM layout, VMA/LMA relocation, vector tables, and stack boundaries.
  • Author bare-metal C startup code (CRT0) that initializes .data from Flash to RAM, zeroes .bss, and calls main().
⚡

3. Reactive Concurrency & Ring Buffers

  • Architect cooperative non-blocking superloops and timer schedulers that banish processor-freezing delay() loops.
  • Write lock-free Single-Producer Single-Consumer (SPSC) circular buffers using power-of-two masking and C11 memory fences.
  • Manage NVIC hardware interrupt priorities, minimizing interrupt latency, context overhead, and avoiding reentrancy traps.
🛡

4. Safety-Critical Standards & State Machines

  • Implement deterministic 2D Table-Driven Finite State Machines (FSMs) providing $O(1)$ event dispatch and action callbacks.
  • Comply with MISRA-C:2012 safety guidelines: eliminating dynamic memory (malloc), unbounded loops, and unverified returns.
  • Integrate hardware Independent Watchdog (IWDG) supervision and author assembly HardFault traps for crash register unwinding.
🖈

5. Layered Architecture & Unit Testing

  • Architect firmware in clean decoupled layers (Application → Service → Driver → HAL → BSP) using opaque handles.
  • Write 100% portable hardware-agnostic device drivers (I2C/SPI) using interface function pointer contracts.
  • Implement host-based Unit Testing with Unity and CMock on Linux/WSL, achieving high branch coverage prior to silicon flashing.
🚀

6. Dual-Target Production CI/CD

  • Inspect ELF binaries using objdump, size, and nm to enforce automated flash/SRAM budget gates.
  • Automate firmware quality gates using GitHub Actions CI: compiling with -Werror, running static analysis, and archiving binaries.
  • Flawlessly transition code between host simulation on Linux/WSL and physical silicon deployment on STM32.
