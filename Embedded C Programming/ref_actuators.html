Actuators, Motors & Power Driver Electronics

Actuators are the physical muscles of embedded systems. They convert low-power microsecond digital pulses generated by a microcontroller into macroscopic torque, fluid displacement, linear motion, or acoustic pressure.

Because an MCU output pin is strictly limited to 3.3 Volts and 10 to 20 milliamps, connecting a high-power inductive motor, solenoid valve, or high-voltage contactor directly to silicon will instantly vaporize the bond wires. Firmware developers must understand power electronic topologies — H-bridges, gate drivers, inductive flyback suppression, and dead-time insertion — to avoid blowing up hardware.

2.2 Inductive Kickback & Flyback Diode Protection

An inductor stores energy in its magnetic field ($E = \frac{1}{2} L I^2$). When the switching transistor abruptly cuts off current, the magnetic field collapses instantly. By Faraday's law of induction:

V_{induced} = -L \cdot \frac{di}{dt}

Because $\frac{di}{dt}$ is extremely large (cutting off 2 Amperes in 10 nanoseconds), the induced voltage can easily spike to several hundred or thousand volts! Without a Flyback Diode placed in reverse bias directly across the coil, this voltage exceeds the drain-to-source breakdown rating ($V_{DS}$) of the MOSFET, destroying the driver instantly.

2.3 Peak-and-Hold Economizer Firmware Pattern

Electromagnetic solenoids require high magnetic flux to overcome inertia and mechanical spring tension to pull the plunger. However, once the magnetic circuit is closed, maintaining the valve position requires only 20% to 30% of that current. Continuing to supply full current overheats the coil and wastes battery energy: 

#include <stdint.h>
#include <stdbool.h>

typedef enum {
    VALVE_STATE_CLOSED,
    VALVE_STATE_PULL_IN,
    VALVE_STATE_HOLD
} ValveState_t;

typedef struct {
    ValveState_t state;
    uint32_t transition_time_ms;
    uint8_t pwm_duty_cycle;
} ValveController_t;

static ValveController_t s_valve = { VALVE_STATE_CLOSED, 0U, 0U };

void Valve_CommandOpen(void) {
    s_valve.state = VALVE_STATE_PULL_IN;
    s_valve.transition_time_ms = millis();
    s_valve.pwm_duty_cycle = 100U; /* 100% full pick current */
    bsp_pwm_set_duty(s_valve.pwm_duty_cycle);
}

void Valve_Step(void) {
    const uint32_t now = millis();
    if (s_valve.state == VALVE_STATE_PULL_IN) {
        /* Hold full pull-in current for exactly 40 milliseconds */
        if ((now - s_valve.transition_time_ms) >= 40U) {
            s_valve.state = VALVE_STATE_HOLD;
            s_valve.pwm_duty_cycle = 25U; /* Drop to 25% PWM holding current */
            bsp_pwm_set_duty(s_valve.pwm_duty_cycle);
        }
    }
}
