Sensors, Transducers & Signal Acquisition

In embedded systems, sensors represent the physical senses of the machine. A sensor transforms physical quantities — acceleration, angular velocity, photons, magnetic flux, mechanical strain, or temperature — into electrical signals.

Writing professional Embedded C drivers for sensors requires mastering not only the register maps in datasheets, but also the physical phenomena being measured, the signal conditioning chain (amplification, anti-aliasing filtering, ADC quantization), bus throughput constraints, and power-saving hardware FIFO buffers.

1.3 Fixed-Point Exponential Moving Average (EMA) Sensor Filter

Raw sensor readings are frequently contaminated with high-frequency noise. Because constrained microcontrollers like Cortex-M0+ lack hardware floating-point units (FPUs), standard floating-point filters trigger software emulation library bloat. Below is an industrial-grade, zero-allocation fixed-point Exponential Moving Average (EMA) filter: 

#include <stdint.h>

/* Q16 Fixed-Point Exponential Moving Average Filter */
#define EMA_ALPHA_Q16 (6554U) /* Alpha = 0.1 in Q16 (0.1 * 65536) */

typedef struct {
    int32_t filtered_value_q16;
    uint8_t initialized;
} EmaFilter_t;

int32_t EmaFilter_Update(EmaFilter_t *filter, int16_t raw_sample) {
    int32_t sample_q16 = ((int32_t)raw_sample) << 16;

    if (!filter->initialized) {
        filter->filtered_value_q16 = sample_q16;
        filter->initialized = 1U;
        return (int32_t)raw_sample;
    }

    /* y[n] = y[n-1] + alpha * (x[n] - y[n-1]) */
    int64_t diff = (int64_t)sample_q16 - filter->filtered_value_q16;
    filter->filtered_value_q16 += (int32_t)((diff * EMA_ALPHA_Q16) >> 16);

    /* Return integer representation */
    return (filter->filtered_value_q16 + 32768) >> 16;
}
