Topic 11

Events and Event Handling

Events turn hardware occurrences into a vocabulary shared by drivers, queues, services, and state machines: button edges, timer expiry, received bytes, samples, and faults.

enum event_type { EVENT_NONE, EVENT_BUTTON, EVENT_TIMER, EVENT_FAULT };

Producers capture events; consumers process them. Keep event payloads bounded and define behavior for queue-full and unknown-event cases.
