Topic 21

Modular .c and .h Files

A header declares the public contract. A source file implements it and keeps private helpers or state static. Header guards prevent duplicate declarations.

/* led.h */
#ifndef LED_H
#define LED_H
void led_init(void);
int led_set(unsigned enabled);
#endif

Compile modules independently, expose only what callers need, and keep implementation details behind the API.
