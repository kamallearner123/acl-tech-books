Callbacks and Timers

A callback is a function pointer supplied by a caller. Timers use callbacks or events to notify application code without owning application policy.

typedef void (*timer_callback_t)(void *context);
struct Timer { uint32_t deadline; timer_callback_t callback; void *context; };

Document callback lifetime, context ownership, execution context, repetition, and whether blocking is allowed.
