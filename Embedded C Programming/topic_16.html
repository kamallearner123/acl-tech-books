Topic 16

Defensive Programming

Validate pointers, lengths, ranges, states, and return values at boundaries. Initialize objects, define safe defaults, avoid undefined behavior, and make failures observable.

int copy_bytes(uint8_t *dst, size_t cap,
               const uint8_t *src, size_t length)
{
    if (dst == NULL || src == NULL || length > cap) return -1;
    for (size_t i = 0u; i < length; ++i) dst[i] = src[i];
    return 0;
}
