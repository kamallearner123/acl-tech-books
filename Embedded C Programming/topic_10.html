Topic 10

Git Workflow

Git records the evolution of firmware and makes changes reviewable and reversible.

git status
git diff
git switch -c feature/gpio-driver
git add gpio.c gpio.h tests/
git commit -m "Add bounded GPIO driver API"
git log --oneline

Keep commits focused, include build/test evidence, and never commit generated binaries or unexplained configuration changes.
